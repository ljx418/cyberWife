# UX10 开发前 PRD 规格检视

**检视基线**：`docs/PRD.md` 2.2
**阶段结论**：计划与V1范围一致，未提前实现V2架构扩容。

| PRD/决议 | UX10覆盖 | 结论 |
|---|---|---|
| G-V2定向体验授权 | 极端窗口、背景、Idle、记忆工作台的V1低风险修补 | ALIGNED |
| FR-10人物画面与降级 | 背景/人物独立回退、Idle不黑屏，保留实时口型验收 | ALIGNED |
| FR-11设置抽屉 | 背景选择和记忆新增/确认仍在现有设置结构内 | ALIGNED |
| FR-12记忆可查改删 | 补齐手工新增、候选可见/确认，不降低来源、编辑、删除审计 | ALIGNED |
| FR-16响应式与可访问性 | 新增2160×3500和3840×180扩展视口；原三视口继续回归 | ALIGNED / STRICTER |
| NFR-02资源 | 生成与实时模型串行，既有RAM/VRAM门不变 | ALIGNED |
| NFR-04隐私/离线 | 背景本地；记忆本地；原始音频不落盘；零公网依赖 | ALIGNED |
| V2边界 | 不新增多形象、多空间、导入导出、图谱或插件端口 | NOT PREMATURE |

UX10完成只能证明机器和产品入口达到人工总验收前状态，不能替代用户对口型、Idle、声音和沉浸感的最终评分。
