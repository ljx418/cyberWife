# UX10 V1 人工总验收前体验修补验收标准

| 编号 | 用户场景 | 操作与证据 | 出门门槛 |
|---|---|---|---|
| UX10-AC01 | 在标准、手机、2160×3500和3840×180窗口打开主舞台 | Headless Chrome逐视口截图、DOM边界、横纵滚动检查 | 无裸露空白、横向溢出或不可达主操作；字幕可见；人物脸部安全区与条幅降级符合规格 |
| UX10-AC02 | 在设置中依次选择不同背景并刷新/重启页面 | 至少4张本地背景、网络请求清单、持久化状态与截图 | 4/4可切换；选择跨重启；零公网请求；加载失败回退而不黑屏 |
| UX10-AC03 | 当前人物进入Idle并循环播放 | 视频时间、黑帧检测、至少5次循环和人工复验入口 | 停止对话后持续播放；无纯黑帧；候选未批准时不得替换当前素材 |
| UX10-AC04 | 新生成低幅Idle候选 | 固定人物真实视频、脸框/背景运动与首尾接缝报告 | 摄影机/背景稳定；脸框中心P95位移≤画面对角线2.5%，脸框面积CV≤3%；接缝机器门通过；人工自然度待总验收签署 |
| UX10-AC05 | 空记忆列表中手工新增一条事实，再编辑和搜索 | REST、UI、SQLite/FTS/vector检查 | 创建、编辑、搜索均成功；来源=`manual`；时间/编辑状态可见；审计事件存在 |
| UX10-AC06 | 会话产生低/中置信候选并查看 | 真实completed turn、候选API和UI | 未确认候选召回命中为0；来源/原因可见；拒绝不落长期记忆 |
| UX10-AC07 | 显式确认候选后在下一轮召回，再删除 | 确认API、真实检索、删除后源/FTS/vector/派生缓存检查 | 只确认一次且去重；确认后可召回；删除后所有位置和召回命中为0 |
| UX10-AC08 | 键盘与读屏完成背景选择和记忆新增/确认 | Playwright键盘旅程、axe、焦点与`aria-live` | 严重/致命axe=0；焦点可见且不丢失；状态可播报 |
| UX10-AC09 | 组合回归 | Backend、根工具、Avatar、前端build/Playwright、V1FINAL核心 | 全绿；开放P0/P1=0；V1首响、打断、资源、隐私和离线门无回退 |

机器门不能替代以下最终人工判断：背景沉浸感、人物构图偏好、Idle自然度、口型同步和声音自然度。UX10只把产品推进到可进行这些判断的人工总验收入口。
