# UX10 V1 人工总验收前体验修补计划

**日期**：2026-10-06
**状态**：实现与自动化验收完成；低动作候选待人工总验收确认后激活
**目标**：在不改变单活动形象、实时对话协议和硬件预算的前提下，关闭极端窗口、独立背景、Idle动作幅度和记忆可操作性四项人工总验收前缺口。

## 1. 入口与边界

- 入口基线：UX9自动化PASS、V1FINAL工具完成、INST1-AC07通过；当前开放项仅为现场人类感知/物理设备门及本轮新批准体验修补。
- 保持`TurnPipeline`、六态、generation取消、A/V时钟、单活动Avatar和现有数据库权威边界。
- 不引入多形象、多空间、图谱、MCP/RAG/CLI插件或全身生成；这些属于V2。
- 背景只作为本地展示资产，不改变人物身份、服装或实时Avatar输入。
- Idle只调整离线生成约束与质量门，不用Idle结果替代说话口型验收。
- 私有图片、视频、记忆正文和生成过程不进入Git；Git只保存无人物的通用背景和脱敏测试证据。

## 2. 子阶段与开发顺序

### UX10.1 极端窗口与本地背景

1. 引入按宽高比判断的`standard/portrait/ultratall/strip`舞台模式，而不是只按宽度断点。
2. 2160×3500使用超高构图；3840×180使用条幅模式，只保留脸/肩安全区、单行字幕和核心语音操作。
3. 生成并内置至少4张无人物、无文字、统一电影感的本地背景；允许在设置中选择并跨重启保存。
4. 背景层与人物层彻底分离；资源失败时回退到当前人物模糊背景。
5. 为4个目标视口增加Playwright布局、键盘和截图证据。

### UX10.2 低幅 Idle 约束

1. 更新Idle工作流正向/负向提示词：固定摄影机、固定背景、微呼吸、自然眨眼、极小头肩运动、闭嘴静息。
2. 保留10秒、首尾连续和人工批准门；不自动替换当前已批准素材。
3. 对新生成候选计算脸框中心位移、尺寸波动、黑帧和循环接缝；生成模型仍带来转头时，使用固定首帧加羽化局部眨眼的确定性衰减层；越门不允许激活。
4. 如果重新生成需要占用前台GPU，只在实时服务停止后串行执行，完成后恢复并复检四组件。

### UX10.3 记忆新增与候选确认

1. 增加手工新增记忆API和界面；来源标记为`manual`，创建、编辑、删除均保留审计事件。
2. 增加当前会话记忆候选查询与显式确认接口；候选未确认前不进入召回。
3. 明确界面提示“自动提取发生时间”和空列表原因；用户无需先触发某个固定句式才能使用记忆。
4. 手工/确认后的记忆复用现有SQLite、FTS5和sqlite-vec事务；删除后各索引及召回命中必须为0。

### UX10.4 组合回归与发布重签

1. 运行前端build、Playwright、Backend、根工具、Avatar测试和V1FINAL核心测试。
2. 重跑UX10专项真实浏览器用例，并保存中文HTML报告和截图。
3. 更新PRD检视、实施后审计、全局状态和V1FINAL当前revision说明。
4. UX10自动门全绿后，才重新进入人工总验收。

## 4. 证据与停止条件

每个子阶段完成后必须更新`acceptance-report.md`对应章节并执行PRD检视。出现以下任一情况立即停线：

- 极端窗口需要删除核心操作或使键盘/读屏不可达；
- 背景资产包含人物、水印、文字或需要公网加载；
- Idle提示调整造成人物身份、服装或背景漂移，或候选未经人工确认自动激活；
- 候选记忆未经确认进入召回，或删除后任一索引仍命中；
- V1首响、打断、口型、资源、隐私或一小时稳态门回退；
- 为本轮功能引入多角色、多空间或通用插件平台。
