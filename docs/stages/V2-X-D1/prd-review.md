# V2-X-D1 PRD规格检视

**结论**：PASS；V2-R01～R14、V2X-AC01～15均有实现责任和真实证据合同，未引入V2-A承诺。

- 交互方向与G-V2X-D0一致：单人物同场景、无第二遮罩、输入可兜底、素材需确认、记忆可追溯、音频优先。
- V1硬门未放宽：首响P95≤7秒、打断P95≤400ms、项目RAM≤14GB、VRAM≤22GB、余量≥2GB。
- 用户提出的高清与嘴部自然度明确属于X8和AC08，不能由分辨率标签、插值或Idle动作代签。
- 多角色、多空间、导入导出、MCP/RAG/CLI插件仍属于V2-A；D1只保留稳定UUID和port迁移锚点。
- D1只是文档门，所有V2-X功能状态仍为“待实现”。
