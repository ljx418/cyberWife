# INST1-AC06 外部视角审查

**日期**：2026-10-06
**结论**：历史结论已撤回并由AC06R外审取代；正式环境证据仍缺失。

## 审查一：是否真的证明“另一环境”

执行器不接受单一自报字段，而是分别比较Windows用户SID哈希和WSL`/etc/machine-id`哈希；换用户但克隆WSL、或换WSL但仍使用开发用户，都会失败。另要求数据根、两个venv和runtime配置执行前全部不存在。当前机真实负例因Windows身份命中在写入前退出1，配置mtime不变。

结论：防当前机/克隆冒签合同PASS；只有新环境实跑才可签AC06。

## 审查二：是否覆盖安装与运行，而不只是文件检查

正式路径固定为离线wheelhouse prepare、显式CosyVoice源码复制、17项verify、start×2、status、Avatar强制recover、stop×2。每个运行态步骤重新检查LLM/Speech/Avatar/Avatar-control/Gateway五个功能健康端点；停止步骤验证五端口和PID记录归零。

结论：覆盖从依赖准备到运行恢复/清理的完整用户部署路径，不是“文件存在即PASS”。

## 审查三：安全、隐私与架构冲击

工具不创建用户、不注册/注销WSL、不安装驱动、不下载依赖或模型；只编排已有安装器和启动器。报告保存身份哈希、版本/revision、布尔前置和步骤结果，不保存身份原文、用户名、工件路径或日志正文。失败后只调用受管stop，继续受PID所有权门保护。

结论：无新增Critical/P0、无产品架构改变、无公网或破坏性系统动作。

## 审查四：回归与文档一致性

安装合同10/10、根回归23/23、PowerShell AST 2/2、前端build/Playwright15/15和取证核心3/3通过；PRD、架构、项目状态、追踪矩阵、安装手册、命令清单和8页Draw.io均仍把正式新环境门标为OPEN。
