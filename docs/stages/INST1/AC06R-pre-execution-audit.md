# INST1-AC06R 开发前审计

结论：允许实施，无新增致命/重大规格偏差。

- PRD 一致性：保留全本地、离线优先、用户授权资产、功能探针和一键生命周期要求。
- 隐私：仓库不携带用户媒体；制品清单只在本地使用，审计报告仅记录逻辑 ID、相对发布目标和哈希。
- 架构冲击：新增安装边界适配器，不改变会话、ASR、LLM、TTS、Avatar 运行时协议。
- 迁移：现有开发机的 `model-registry.local.yaml` 与数据根保持可用；只有显式传入制品清单时才执行 bootstrap 发布。
- 回滚：移除 `-ArtifactManifestWsl` 即保持既有安装审计行为；准备器采用临时目录后原子发布，失败不覆盖有效配置。
- 剩余风险：第三方模型/素材的取得与授权不能由代码代替，必须由清单中的本地声明和外部审查承担。
