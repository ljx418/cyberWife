# INST1-AC07 单机隔离可移植性开发计划

## 目标

在不虚构第二台机器的前提下，为单机所有者建立可失败关闭的 V1 部署门，并保留独立干净机增强路线。

## 顺序

1. 用 ADR-012 固定降级范围与不覆盖项。
2. 先扩展最终聚合器合同测试，确保 AC06/AC07 schema 不可互相冒充。
3. 实现 AC07 报告构建器和 Windows 生命周期入口。
4. 复算 release、隔离 venv、wheelhouse、制品、前端与路径参数化证据。
5. 真实运行 start×2/status/recover/stop×2；宿主互操作不可用时保持 PENDING。
6. 更新 PRD、架构、计划、追踪矩阵、安装手册和总门。
7. 执行全量回归、PRD 检视和内外部审计。

本阶段不改模型、不改用户交互、不写入私人音频/对话，也不突破 16GB 空闲内存预算。
