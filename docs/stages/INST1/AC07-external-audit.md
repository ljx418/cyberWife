# INST1-AC07 外部视角审查

## 独立审查结论

1. **语义**：文档统一使用“单机隔离可移植性”，没有把当前机称为干净机或跨机器兼容。
2. **架构**：新增内容只位于验收层；安装器、RuntimeLauncher、模型拓扑和用户交互未迁移，架构冲击低且可回滚到AC06策略。
3. **证据**：历史隔离/no-index证据必须被当前release逐文件绑定；当前生命周期必须重新运行，不能只复用顶层PASS。
4. **失败模式**：AC06与AC07 schema互斥；三项未验证边界是强制字段；缺当前revision报告保持PENDING。
5. **残余风险**：无法发现另一台电脑上的驱动、WSL内核、文件权限或硬件差异。对单用户私人V1可接受，但不支持“任意机器可安装”的宣传。

结论：文档和实现足以指导AC07实跑，无新增Critical/Major规格冲突；在真实Windows生命周期完成前只可标记IMPLEMENTED/PENDING。
