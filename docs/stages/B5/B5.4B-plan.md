# B5.4B 五步设置与设置抽屉真实闭环计划

**状态**：READY FOR IMPLEMENTATION  
**入口**：B5.4A PASS，开放P0/P1=0。

## 目标

在不改变G-UX批准视觉的前提下，将默认五步设置和设置抽屉剩余占位行为接到真实本机服务：草稿续接、授权、六组件运行检查、人物/声音文件校验和版本激活、人设保存、完成标记、会话中“不记录”切换。

## 实施实体与顺序

1. `ConversationClient`增加multipart资产预览/入库接口；复用既有激活、恢复、profile、draft、consent API。
2. `App/Onboarding/SetupStep`启动读取draft/profile；每步后端保存成功才推进；授权同时写consent；运行检查展示真实六组件/资源；人物与声音执行真实文件上传并激活；人设完成以乐观版本保存；`settings_json.completed=true`作为跨重启完成标记。
3. 设置抽屉的人物/声音支持真实选择、校验、激活和恢复；描述移除“原型”。
4. 隐私开关在会话前决定创建策略；会话中启用调用`PATCH /sessions/{ref}/no_record`并切换到新的opaque ref/WS，失败时UI回滚。
5. 用隔离DB/资产目录完成Chrome五步5次、异常文件拒绝、跨服务重启续接和设置操作，再做PRD检视。

## 不变量

- 未授权上传始终403；前端勾选不能冒充后端授权。
- 文件失败不推进步骤、不改变active SHA；上传结果不显示绝对路径。
- `completed`只在最终profile与所选资产均保存成功后写入。
- 会话中不记录切换失败必须保持原策略并明确提示，禁止只改视觉开关。
