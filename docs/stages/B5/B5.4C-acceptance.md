# B5.4C 验收标准

## C-GATE-0 开发前审计

- PRD、目标架构、接口合同和当前代码四向映射完成。
- P0=0；P1必须有本阶段可执行闭环；不得把历史单项证据冒充组合证据。

## C-GATE-1 合同与可访问性

1. 18类标准错误保持稳定`error.code`；带安全说明的detail仍映射到其标准前缀。
2. 健康未返回前显示“加载中”，Gateway不可达显示错误，不得硬编码“本地在线”。
3. 1920×1080、1366×768、420×720均无横向溢出或关键控件遮挡。
4. 设置对话框Tab/Shift+Tab闭环，Escape关闭并恢复到触发按钮；自动审计0 critical/serious。
5. 六态与错误状态通过live region播报；reduced-motion不丢失信息。

## C-GATE-2 降级

1. CosyVoice启动/功能probe失败时，先释放失败对象，再单向启动Qwen；两者不得双常驻。
2. 回退后health显示`degraded`、`fallback_active=true`和当前logical id；用户单项恢复才允许下一会话尝试Cosy。
3. 运行中TTS失败时文字final仍到达、音频终止且界面说明文字降级；Avatar失败时音频继续且2秒内静态降级。

## C-GATE-3 真实组合

- AC-01/02：5次首次设置；异常资产拒绝、真实裁切/试听/激活/恢复。
- AC-03：固定中文10轮+自然语料10轮，成功≥19/20。
- AC-04：普通缓存未命中30条，P95≤7s；VRAM/RAM/余量/队列全部达门。
- AC-04A：正例、至少24负例、版本失效、≤64MiB且无磁盘写。
- AC-05：30次打断，P95≤400ms，旧generation写入0。
- AC-06：媒体/final/infer≥25fps，backlog≤3，三周期降级恢复。
- AC-07～10：使用真实SQLite、sqlite-vec、文件目录验证召回、删除、不记录和30天清理。
- AC-11～13：按本文件C-GATE-1、恢复runner及修订后的AC-13执行。

## 出门

C-GATE-0～3全部PASS、开放P0/P1=0，才可进入B5.5；B5.5仍需1小时稳定性、一键启停、备份/恢复/卸载/清除演练。
