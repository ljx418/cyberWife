# B5.4B 验收标准

1. 空库五步：5次Chrome从未授权开始；未勾选无法上传；授权后依次看到六组件真实状态，导入有效图片/WAV，保存完整人设并进入idle。成功率5/5。
2. 自动保存续接：每一步关闭页面并重启Gateway/页面，重新打开回到最近未完成步骤且已保存字段100%一致；完成后普通根路由直接进入主舞台。
3. 资产异常与版本：损坏、伪扩展、超限文件拒绝率100%；两个有效版本激活/恢复后的active SHA正确；UI和错误均无绝对路径。
4. 设置抽屉：人物、声音、人设、记忆、隐私、运行状态六类均产生真实API；人物/声音替换与恢复无需刷新。
5. 不记录：会话前开启创建opaque session；标准会话中开启必须由后端返回新opaque ref并删除当次既有业务记录；失败时开关回滚。

证据写入`audit/v1/B5/B5.4B-onboarding/`；前端构建、后端全回归、B5.3白盒必须同时通过。
