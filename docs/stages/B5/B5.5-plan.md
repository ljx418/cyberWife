# B5.5 生命周期发布计划

**状态：READY FOR IMPLEMENTATION**  
**入口：** B5.4C PASS，开放P0/P1=0。

## B5.5A AC-14稳态与运行生命周期

1. `RuntimeLauncher start`连续两次、`status`；第二次不得产生新PID。
2. 当前候选运行60分钟，至少20个完整真实轮和10次真实打断，每5秒采样RAM/VRAM、两侧可用内存、swap、task、queue和延迟。
3. 单组件recover后执行功能probe；`stop`连续两次，端口/PID/临时音频归零；为后续演练重新启动。

硬门沿用命令清单：RAM≤14GiB、VRAM≤22GiB、Windows/WSL可用≥2GiB；后30分钟斜率RAM≤20MiB/min、task/queue≤0.1/min、延迟P95≤20ms/min；连续3分钟swap-in≥1MiB失败。

## B5.5B 数据生命周期

- 备份在服务停止或SQLite在线backup API的一致快照上进行，包含数据库、配置、人物/声音资产和manifest哈希，不包含模型、缓存、日志或验收证据。
- 恢复只允许到隔离数据根演练；先校验manifest/hash，再原子替换；验证`PRAGMA integrity_check`和资产引用。
- 卸载演练只移除应用运行实体/快捷入口/受管PID记录，默认保留用户数据。
- “清除全部数据”是独立动作，必须精确确认；正式验收仅对隔离副本执行，生成只含计数/哈希的脱敏收据。
