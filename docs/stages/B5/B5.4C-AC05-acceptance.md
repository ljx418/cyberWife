# B5.4C AC-05 验收标准

| 检查项 | 硬门 |
|---|---|
| 样本 | 早/中/晚各10次，共30/30通过 |
| 用户感知静音 | 从发送打断到浏览器旧音源归零P95≤400ms |
| 旧代次 | `post_detected_old_audio=0`；取消代次准确；旧字幕/帧/DB后续增量0 |
| 媒体连续性 | AudioContext不关闭；Avatar保持ready；连接代次不变；重连次数0 |
| 取消健康 | `component_errors=[]`；每次返回listening；未处理异常0 |
| 收尾 | active turn、LLM/TTS/outbound队列归零；下一新轮可完成 |

证据必须来自本次同一发布候选的真实Chrome逐行CSV、JSON manifest和运行时快照。
