# B5 详细开发计划：规格补齐、发布硬化与 V1 总验收

**状态**：PLANNED；尚未进入产品代码开发  
**前置门**：B3、B4 PASS；B0/B1/B2/B2.5 证据仍有效；B5 文档审计 P0/P1=0  
**目标体验**：用户从一个入口启动，在本机断网环境中完成设置、无限多轮交谈、打断、记忆和恢复，并能安全退出、备份或清除数据。

## 1. 发布完整性补齐

B5先实现当前仍缺失、但 AC-01/02/11要求的合同，而非直接跑总回归：

- 授权授予/撤销、撤销后的素材阻断和脱敏审计。
- 人物/声音资产版本列表、预览、原子激活、失败不切换和上一版本恢复。
- 完整人设字段、乐观并发和跨重启一致性。
- 已批准沉浸式 `App.tsx` 成为默认入口；旧M2上传页仅保留开发模式入口。
- 设置抽屉接入真实人物、声音、人设、记忆、隐私和运行状态 API。
- 浏览器 HostBridge 保持安全空实现，不引入桌面壳。

这部分只允许合同接线和必要回归修复，不重做视觉设计。

### 1.1 B5.1 完整性硬门

B5.2 前必须执行 [`acceptance-command-manifest.md`](../../acceptance-command-manifest.md) 的 B5-AC00 并返回0。门内逐项验证实际 HTTP/WS 状态、数据库结果与 Chrome 页面：授权撤销后资产API为403/不可选；资产激活失败保持旧版本；人设版本冲突为409；根路由默认主舞台且 `?legacy=1` 可回退；人物/声音/人设/记忆/隐私/运行状态六类设置均有真实API；HostBridge在纯浏览器环境返回明确 unsupported 而不调用本机特权。证据不完整即停止，禁止进入组合回归。

## 2. 故障、断网与生命周期

1. 逐个终止 LLM、ASR、TTS、Avatar、Embedding；另测端口占用、模型路径损坏和探针失败。
2. 用户页面3秒内显示组件、影响和恢复动作；`POST /api/v1/launcher/recover` 是真实恢复入口。
3. 断开公网后执行启动、5轮对话、记忆查改删、资产替换和恢复。
4. 监测监听地址、DNS/HTTP/TCP；允许集合仅为loopback和启动时解析、写入证据manifest的Windows↔WSL本机桥接地址，允许集合外已建立连接必须为0；不以内核广播噪声冒充项目出站。
5. 完成start两次、status、1小时混合使用、recover、stop两次；停止后端口/PID/临时音频为0。

## 3. 发布与数据演练

- 冻结依赖、配置、数据库migration、模型revision/SHA256和许可证。
- 执行全量备份→破坏性测试副本→恢复→数据库完整性和模型引用校验。
- 卸载应用不得隐式删除用户数据；数据清除必须独立二次确认并生成脱敏结果。
- 同步 ComfyUI 模型保留索引：CosyVoice2为默认，Qwen3-TTS为显式受保护回退；未覆盖模型只生成候选报告，不自动删除。
