# B5.4C AC-06 验收标准

| 场景 | 出门门槛 |
|---|---|
| 正常嘴型 | 真实音频驱动；浏览器finalfps≥25；服务端inferfps≥25；decoder backlog≤3 |
| Avatar故障 | 受管PID标记校验；≤2秒进入static_fallback；故障后音频块>0；文字final非空 |
| 同页恢复 | 3/3周期ready；连接代次增加；页面reload=0；恢复轮不再fallback |
| 存活判定 | WS间隙心跳500ms；客户端1200ms watchdog + 控制探针≤500ms；总降级≤2秒 |
| 健康忙碌 | 独立8011健康；不得误降级/重连；控制存活时媒体停滞只软降级并保留原session |
| 隐私边界 | 8010/8011仅loopback；控制响应无用户内容；不新增落盘或公网请求 |
| 迟帧 | server late_video_frames_dropped=0，客户端旧代次帧不显示 |
| 资源/收尾 | RAM≤14GiB、VRAM≤22GiB、两侧可用≥2GiB；任务与队列归零 |

必须保留每周期故障时刻、降级时延、恢复快照、FPS和完整结果JSON。
