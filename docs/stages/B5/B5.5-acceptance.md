# B5.5 验收标准

| 场景 | 出门门槛 |
|---|---|
| start×2/status | 第二次不换PID；四组件functional healthy；仅loopback |
| 60分钟 | 20完整轮+10打断全PASS；无OOM/未处理异常；资源与斜率达门 |
| recover/stop×2 | 单项恢复不动健康组件；重复stop成功；8010/8011/7860/8090/8091关闭；PID记录归零 |
| 备份恢复 | manifest全哈希一致；隔离恢复DB integrity=ok；配置和资产引用完整 |
| 卸载 | 数据根字节/哈希不变；只清应用运行实体，不隐删用户数据 |
| 清除数据 | 无精确确认拒绝；仅隔离根执行后业务DB/资产/备份消失；脱敏收据不含正文/路径外内容 |
