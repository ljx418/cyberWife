# B5.4A 开发前审计

**结论**：规格和实体边界完整，P0/P1设计风险已闭环，允许实施。

| 发现 | 等级 | 闭环 |
|---|---:|---|
| 默认批准页面仍以定时器模拟状态，FR-07/08不能验收 | P1 | 删除主路径模拟入口，状态由真实WS信封驱动 |
| 未挂载旧组件有`MediaSession.start`但没有麦克风采集 | P1 | 新建单一输入服务，复用既有输出与Avatar服务 |
| 浏览器常见48k输入与后端16k/640B合同不一致 | P1 | AudioWorklet重采样、20ms定长帧与合同测试 |
| 前端插话可能只改视觉状态 | P1 | 必须发送控制帧并同步取消Media/Avatar generation |
| 连续监听误把背景噪声切成大量turn | P1 | 启动阈值、前置缓冲、静音hangover、最大30秒封口 |
| 结束会话遗留设备/连接 | P1 | stop路径幂等释放，E2E读取资源快照签署 |
| 接线破坏已批准视觉 | P1 | 只替换数据与动作，不改变DOM主结构；三尺寸回归留到B5.4C |

开发前开放P0/P1：0。若Chrome无法提供真实麦克风输入，允许使用Chrome受控虚拟音频设备作为真实媒体输入，但不得调用页面内部模拟函数。
