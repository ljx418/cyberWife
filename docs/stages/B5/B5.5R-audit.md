# B5.5R 开发前审计

**结论：PASS，允许进入 B5.5R 实施；开放 P0=0、P1=0。**

| 审计项 | 结论 | 依据 |
|---|---|---|
| PRD 一致性 | PASS | 不改模型、交互和 7 秒首响门；只收敛 TTS 调度生命周期并增强验收证据 |
| 架构一致性 | PASS | Gateway 仍拥有 TTS/MediaPipeline；未新增进程、端口、网络或数据边界 |
| 硬件预算 | PASS | 单工作线程限制并发扩张，预期降低而非增加 RAM；VRAM 模型驻留不变 |
| 打断安全 | PASS WITH TEST | 取消钩子不提交到 TTS 专用单线程，避免被长推理排队；必须由真实短诊断验证 |
| 验收真实性 | PASS | 维持 60 分钟、真实模型、20+10 动作和全部原门槛；不以重算旧证据替代重跑 |
| 清理安全 | PASS | 只停止 launcher 持有且 marker 匹配的 PID；失败证据与清理结果分别记录 |

## 已闭环意见

- **禁止直接放宽 task 斜率：** 已保留 `<=0.1/min`。
- **禁止以总数掩盖归属：** 计划增加组件级 task/RSS 字段。
- **禁止失败后遗留服务且无证据：** 计划以 `finally` 强制收尾并始终写 `lifecycle.json`。
- **禁止短测冒充 AC-14：** 短诊断只作为进入正式 60 分钟验收的前置门。

## R5 失败审计增量

- **事实：** R5 原始 5 秒采样共 457 条，Windows Available 有 30 条低于 2048 MiB（最低 1957.477 MiB，分布于第 17、32、34～36 分钟）；因此即使分钟进度行偶尔高于门槛，本轮也必须 FAIL。
- **非根因：** 19/19 动作成功；Linux task 稳定于 335，Gateway Python 线程稳定于 8，队列归零，累计首响 P95 降至约 6.21 秒。没有证据支持通过降低线程、队列或功能负载来“修复”余量。
- **允许的最小变更：** llama.cpp 当前隐式 `batch=2048/ubatch=512`，而 V1 是单用户、4096 上下文。显式 512/256 仅压缩计算工作区，保持模型、上下文、KV 精度和输出合同不变，架构迁移与体验风险低。
- **拒绝项：** 不关闭用户进程，不放宽 2 GiB/14 GiB 门，不降低 4096 上下文，不把已停止的 36 分钟与新样本拼接；KV 量化未完成独立质量审计前不得启用。
- **入口结论：** 开放 P0=0、P1=1（`B55R-P1-03 Windows余量不足`）；只允许实施 batch 工作区限额及其短门，短门达到 Windows Available ≥2304 MiB 且功能/首响不回退后方可重跑 AC-14。

## R6 失败后的缓存回收审计

- **证据结论：** R6 的 190 条原始样本中 33 条 Windows Available <2048 MiB，最低 1085.922 MiB；项目 RAM 仍≤14 GiB，不能以常驻进程 RSS 解释该瞬时缺口。停止后 WSL `Cached≈7.8 GiB`，一次 clean page cache 回收及延迟气球回收释放约 7 GiB 宿主余量，因果方向与时间序列一致。
- **安全边界：** 仅允许 Linux 标准 `drop_caches=3` 丢弃可重建 clean cache，调用前 `sync`；不得执行 WSL shutdown、不得清 swap、不得杀用户进程、不得改 `.wslconfig`、不得把回收内存排除在资源采样外。
- **体验边界：** 回收发生在四组件预热完成之后且每次全量 start 最多一次；不在对话轮次中执行，不增加首响路径抖动。可用参数显式关闭，便于回滚与环境对比。
- **验收防伪：** 运行期 2 GiB 硬门完全不变；3 GiB×3 连续启动门只增加安全余量，不替代运行期采样。短门和正式门仍使用真实模型、真实动作与全量资源归因。
- **入口结论：** 开放 P0=0、P1=1（`B55R-P1-04 WSL缓存未返还宿主`）；只允许实现一次性可回滚回收及稳定启动门，短门通过前禁止再次正式 AC-14。

### R6续修关闭记录

真实短门 6 完整+3 打断全部通过，Windows Available 最低 5482.645 MiB，较 R6 最低值增加约4.29 GiB；项目 RAM、GPU、P95、线程、task、队列和swap门均满足短门要求。实现不改变模型、上下文、KV精度、回答与媒体路径；回收发生于对话开始前且重复start不重复执行。`B55R-P1-04` CLOSED，开放 P0=0、P1=0，准入正式 AC-14。

当前没有新增致命或重大规格偏差风险，可以开始实现 B5.5R-1～R-3。
