# UX6 验收标准：主舞台 Idle、构图与当前人物口型

**证据目录**：`audit/v1/UX6/`（真人媒体不入 Git）

| ID | 用户场景与操作 | 证据 | 出门门槛 |
|---|---|---|---|
| UX6-AC01 | 打开主页、不开始对话并等待至少 20 秒 | DOM 状态、视频时间、截图 | active Idle 自动静音循环；时间持续推进；不是静态图冒充 |
| UX6-AC02 | 开始一轮、完成播音、结束会话 | 逐状态截图/时间线 | Idle→live→Idle；切换黑帧≤1帧；结束后 Idle 在 500ms 内继续推进 |
| UX6-AC03 | 分别使用 1920×1080、1366×768、420×720、1818×2406 | Headless Chrome截图与像素/DOM边界 | 人脸、头顶和下巴可见；媒体不拉伸；关键文案与脸部核心区不重叠；无横向溢出 |
| UX6-AC04 | 当前 active avatar 播放同一授权 WAV | MP4、PCM/H.264 CSV、active id/source hash | 当前人物与激活记录一致；序号/时钟/FPS仍达UX5机器门；无黑帧和冻结 |
| UX6-AC05 | 对当前人物比较融合/裁切候选 | 同音频并排或盲序视频 | 仅在机器门不回退时选候选；未获人工签署不得切默认 |
| UX6-AC06 | 用户观看最终当前人物交互 | 人工评分 | 口型同步、嘴部自然度、Idle自然度均≥4/5；结束后持续Idle为是 |
| UX6-AC07 | 回归首响、打断、资源和隐私 | 原验收命令与连接采样 | 首响≤7s、打断≤400ms、双FPS≥25、VRAM≤22GB、无公网动作 |

## 防虚假验收规则

1. 另一人物的 UX5 视频不能签署当前 active avatar 的 AC04～06。
2. `inferfps/finalfps` 只能证明吞吐，不能证明音素形状或嘴部自然。
3. Idle 设置页预览不能替代主舞台实际播放。
4. 单张截图不能证明视频持续播放；必须同时记录 `currentTime` 推进。
5. 自动相关性不能替代 AC06 人工观看。
