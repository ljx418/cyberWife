# V1RC1 验收标准

| ID | 场景 | 出门门槛 |
|---|---|---|
| RC1-AC01 | 全量自动化与构建 | 后端、根工具、Avatar、前端构建/Playwright全部通过；无收集错误冒充产品失败 |
| RC1-AC02 | 20轮真实连续对话 | ≥19/20；每轮一次完整TTS；事件序、generation、队列均正确 |
| RC1-AC03 | 30条普通浏览器首响 | 30/30 `normal`，P95≤7秒，缓存命中0，浏览器非静音确认完整 |
| RC1-AC04 | 30次真实打断 | 早/中/晚各10；P95≤400ms；旧音频/字幕/帧/记忆写入0 |
| RC1-AC05 | 60分钟发布生命周期 | 20完整+10打断；无崩溃/OOM/趋势增长；资源全达门；恢复与stop×2通过 |
| RC1-AC06 | UX7普通话与整句口播 | ASR简体归一有效；一轮TTS调用=1；用户UX7人工签署保留 |
| RC1-AC07 | 发布冻结一致性 | PRD/架构/追踪/冻结清单与候选提交一致，开放P0/P1如实列出 |

## 外部门（不由自动化冒充）

- Narrator 真实播报五任务需要人类听感签字。
- 干净 Windows 用户 + 干净 WSL + 驱动/模型组合安装需要独立环境证据。
- UX6 的口型/Idle 完整交互感知只接受用户签署，不以 FPS 或相关性替代。
