# V1RC1 PRD 规格检视

| 规格 | 本阶段验证 | 禁止偏移 |
|---|---|---|
| FR-08 连续本机对话 | 20轮与60分钟真实链 | 不以文字-only或mock替代 |
| FR-09 插话 | 30次和长稳态10次打断 | 不放宽400ms或旧轮零泄漏 |
| FR-10 音画链 | 真实Avatar帧、FPS、故障恢复 | FPS不替代用户口型感知 |
| FR-17 一键生命周期 | start×2/status/recover/stop×2 | 不手工拼装服务冒充一键 |
| FR-20 严格问候缓存 | 普通30条保持normal | 缓存样本不得混入普通P95 |
| NFR-01 | P95≤7秒、打断≤400ms | UX7不修改既定门槛 |
| NFR-02/03 | 资源、1小时、趋势 | 不复用UX7前长稳态签新候选 |
| NFR-04 | 本机链、无原音频落盘 | 不新增出站或正文日志 |

**结论**：V1RC1 是发布候选重新签署，不扩展 PRD。它直接验证 UX7 对既有承诺的影响，并保持所有原始硬门。
