# V1RC1-AC05 开发前审计

**结论**：允许执行固定60分钟入口；Critical=0，Major=0。

| 风险 | 闭环 |
|---|---|
| 短测冒充长稳态 | runner在少于10分钟时固定失败；本次参数明确60分钟 |
| 动作做完后空等 | 30个动作按整小时均匀分布，持续触发真实模型链 |
| Linux cache被误算项目泄漏 | 同时采集项目RSS与`MemAvailable`，趋势只针对项目进程 |
| 偶发swap被夸大/忽略 | 原始页计数保留；连续3个≥1MiB/min才判持续压力 |
| 生命周期清理遗漏 | finally无论成功失败均stop×2，并扫描全部受管端口/PID记录 |
| R3热内存策略导致后期增长 | 以14GiB峰值、2GiB余量与后30分钟斜率三重约束 |

使用既有固定入口，不修改阈值。执行结束会停止全部项目服务，这是验收设计的一部分。
