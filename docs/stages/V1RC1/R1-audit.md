# V1RC1-R1 开发前审计

**结论**：允许修复；不降低 PRD 硬门，不改变模型和前端体验结构。

| 风险 | 闭环 |
|---|---|
| 回复过短损伤陪伴感 | 一条完整自然句，18字而非机械截断；用户可在最终体验门复核 |
| 启动器读取错误人物 | 只接受80字符内安全avatar id；显式参数优先；缺失时回退内置人物 |
| runner修复掩盖产品失败 | runner从真实API读取active id，并在证据中记录/断言；不硬编码Crop V2 |
| 首响仍超7秒 | 真实20轮先筛查，再以30条Chrome作为正式签署；失败继续停线 |

开放 Critical=0；P1 均有失败门，不需要用户做高风险选择。
