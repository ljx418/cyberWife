# V2-X8.0 验收标准

| ID | 场景与步骤 | 出门门槛 |
|---|---|---|
| V2X8.0-AC01 | 读取当前运行配置、数据集manifest和模型代码，追踪PCM到浏览器画面的完整调用链 | 文档中的每个实体可定位到代码；明确模型输入、预测范围、融合范围和时钟；不得把局部贴回误写成人物抠图 |
| V2X8.0-AC02 | 当前人物、当前蓝调客厅、同一8秒WAV分别运行`mouth_oval_v1`和`full` | 输入SHA、源帧、25fps协议一致；黑帧0、序列缺口0、持续冻结0、嘴部真实响应；结果不覆盖active |
| V2X8.0-AC03 | 比较整脸与口周候选 | 候选只有在脸颊净扰动、锐度、上半脸身份变化、二阶运动均不劣于基线时才可进入人工门；任一显著劣化即REJECT |
| V2X8.0-AC04 | 审计MuseTalk 1.5、HeyGem/Duix、LatentSync及本机LiveTalking集成 | 来源、版本、许可证、权重大小、实时性、依赖、硬件和架构改动均有事实依据；不能用商业版或离线演示推断开源实时效果 |
| V2X8.0-AC05 | MuseTalk 1.5本机串行canary | 真实250帧当前人物数据集、真实8秒音频；finalfps≥25、黑帧/序列缺口/持续冻结=0；峰值资源不突破既有硬件门；失败自动保留Wav2Lip |
| V2X8.0-AC06 | 同人物同音频盲评 | 项目所有者对同步、嘴部自然度、身份保持、清晰度分别评分；MuseTalk四项均≥4/5且不低于Wav2Lip才可进入X8迁移，否则保持基线或调整一次参数后重测 |

自动化只可关闭结构、传输、资源、响应和相对画质诊断；口型音素正确性、身份观感与自然度必须人工签署。
