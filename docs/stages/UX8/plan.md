# UX8 开发计划：普通话转写与自然停顿连续性

**日期**：2026-10-06
**问题来源**：用户真实交互反馈“听我说的话显示成粤语，并且说话不连贯”。

## 目标与边界

1. ASR 仍使用本机 Faster-Whisper large-v3-turbo，不增加联网、云 ASR 或新常驻模型。
2. 在现有繁体转简体之后，对 Whisper 偶发输出的高确定性粤语功能词做保守的普通话归一；不得改写普通话实词、姓名或用户原意。
3. 保持 `language=zh`、单轮独立解码和时间戳；增加短小的普通话热词提示，但不得回到 UX7 已否决的长提示或高 beam 路线。
4. 浏览器端点从 600ms 放宽到 900ms，使正常的句中思考停顿仍属于同一轮；30 秒后端上限、20ms PCM、原始音频不落盘和打断合同不变。
5. CosyVoice 继续以每条最终回复一次完整推理，不重新启用“前缀 + 余文”双推理。

## 实施顺序

1. 先增加普通话归一、ASR 参数合同和端点连续性的失败用例。
2. 实现确定性文本归一器，并让全文与逐段字幕使用同一结果。
3. 调整浏览器静音 hangover，补充可观测快照，便于现场确认实际阈值。
4. 运行单元、前端构建/浏览器回归；随后用既有授权真实 PCM 做模型回归，比较文本与耗时。
5. 进行 PRD 检视和实现后审计；物理麦克风主观效果只由用户现场签署，不以合成音频冒充。

## 回滚

- 热词造成字符污染或真实样本语义退化：移除热词，仅保留确定性后处理。
- 900ms 使首响超过 7 秒：退到 800ms，并重新测完整链；不得降低 7 秒门。
- 归一规则出现歧义改写：删除对应规则；规则只允许覆盖粤语特有词形。
