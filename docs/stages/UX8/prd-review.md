# UX8 PRD 规格检视

| PRD | 本轮影响 | 结论 |
|---|---|---|
| FR-08 连续监听、逐句字幕 | 修正普通话展示；句中停顿容忍由 600ms 增至 900ms | ALIGNED |
| FR-10 音画同步与降级 | 不改 PCM 时钟、Avatar 协议和降级路径 | ALIGNED |
| NFR-01 首响/打断 | 增加 300ms 端点等待；ASR-final 后首响口径与 400ms 打断不变 | ALIGNED，物理麦克风待复验 |
| NFR-04 隐私 | 不保存原始麦克风，不增加上传或公网依赖 | ALIGNED |
| NFR-07 资源 | 无新模型；热词和规则表为常量级开销 | ALIGNED |

本轮未改变 V1 功能范围、硬件预算或已批准的 7 秒首响门。机器证据支持实现进入用户复验，但不把授权 fixture 的结果冒充物理麦克风主观通过。
