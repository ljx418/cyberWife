# V2-X0.1 麦克风校准、设备选择与PTT开发计划

**入口**：V2-X0 PASS；D1合同有效  
**目标**：在不替换后端ASR/VAD权威的前提下，降低环境噪声误触发，并提供可恢复的麦克风选择和按键说话兜底。

## 开发顺序

1. 把输入阈值推导抽成纯函数：从2秒RMS样本计算P50/P95噪声底、普通阈值和打断阈值，强制安全上下界。
2. 扩展`InputAudioSessionController`：设备枚举/选择、临时校准、自动/手工/PTT模式、快照和单track切换。
3. 增加“输入”设置页：能力说明、设备、模式、校准进度/结果、手工灵敏度；对不支持设备枚举清晰降级。
4. PTT键仅在对话活动且输入模式为PTT时出现；按下开始许可、释放撤销，焦点丢失/页面隐藏强制释放。
5. 后端只暴露已批准flag；校准摘要保存在当前浏览器会话，不上传、不保存原音频。
6. 纯函数/控制器测试后，用无头Chrome虚拟媒体验证设备切换、校准、PTT门和活动track≤1；噪声误打断70%与真实插话延迟保留给有物理噪声的AC09实测。

## 回滚

关闭`v2x.input_calibration`后不显示输入页，`InputAudioSession.start()`使用V1默认设备和固定阈值。任何校准失败只清除本次摘要并恢复V1值。
