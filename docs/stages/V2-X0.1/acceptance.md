# V2-X0.1 验收标准

| ID | 操作 | 自动化硬门 |
|---|---|---|
| X01-AC01 | 输入安静/稳定噪声/突发噪声RMS序列 | 阈值有上下界；突发值不支配P50；打断阈值始终高于普通阈值 |
| X01-AC02 | 枚举并选择输入设备，活动中切换 | 先停旧track再启动新track；活动track≤1；失败恢复默认设备 |
| X01-AC03 | 执行2秒校准 | 只产生统计摘要，不产生音频Blob/文件/网络请求；失败恢复V1阈值 |
| X01-AC04 | PTT未按/按下/释放/失焦 | 未按下起句=0；按下可说；释放和失焦撤销许可 |
| X01-AC05 | 普通/播放中打断边界回归 | 自动模式沿用onset/hangover；播放态阈值和持续时间更严格 |
| X01-AC06 | 浏览器能力缺失 | 原入口可用，设备选择/校准显示不支持，不虚假成功 |
| X01-AC07 | 构建与回归 | TypeScript build、输入测试、既有Playwright和后端回归无新增失败 |

## 人工/真实环境门 V2X-AC09（本阶段末）

安静、持续风扇噪声、突发生活噪声各完成校准、对话和插话，并切换麦克风与PTT。相对V1误打断减少≥70%，有效插话P95≤400ms且漏触发不增加。若自动化环境不能提供可控物理声场，只能标记AC09待人工，不得伪造PASS。
