## 人工门 G-V2X-D0

项目所有者需要判断：

1. 单人物、同场景、无第二遮罩的方向是否正确；
2. 自动校准默认、PTT兜底和生命周期恢复是否符合使用预期；
3. 多素材、图像描述确认和记忆工作台是否没有偷跑V2-A；
4. 高清口型、音画治理和CosyVoice预设的质量门是否足够严格。

人类未明确批准前，只能继续修订D0或准备非实现性资料，不得进入V2-X产品代码开发。
