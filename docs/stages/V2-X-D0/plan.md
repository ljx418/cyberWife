# V2-X-D0 交互体验对齐计划

**日期**：2026-10-08
**阶段性质**：文档与交互原型，不修改产品运行代码
**入口**：V1FINAL人工PASS；V2-R01～R14均已批准纳入V2-X

## 目标

把V2-X需求转换为人类可审查、开发可实现、验收可复用的交互契约，回答四个问题：

1. V1当前实际界面与链路是什么；
2. V2-X会在同一产品壳中增加什么；
3. 每个组件怎样操作、由哪个代码实体承接；
4. 每条用户旅程如何绑定PRD和验收门。

## 工作顺序

1. 读取PRD、V2总计划、目标架构、V1FINAL证据和当前React/媒体会话代码。
2. 使用真实V1截图建立基线，私人真人截图不加入Git。
3. 形成单人物目标舞台、设备/恢复、素材/场景、记忆、音画/声音五组交互组件。
4. 形成JX-01～JX-05用户旅程和R01～R14追踪表。
5. 用archify生成可探索目标架构图，并执行showcase确定性校验。
6. 用无头Chrome验证页面容纳与关键交互，记录自动化和人工视觉检查边界。
