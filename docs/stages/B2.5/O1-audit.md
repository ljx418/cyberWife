# B2.5-O1 开发前审计

**日期**：2026-09-25  
**结论**：开发前门禁 PASS；开发后复审 PASS，可进入 O2

## 独立检视结论

1. **PRD一致性**：口径保持为 ASR final 到浏览器首个非静音样本；未降低 P50/P95、质量或资源门槛。
2. **架构一致性**：新增能力位于基础设施指标收集、应用编排和既有浏览器媒体服务中；不侵入领域模型，不迁移数据库。
3. **语义一致性**：`generation` 表示会话当前生成代次，`bucket` 表示 mutually-exclusive 测量路径；O1 只产生 `normal`，不把未来缓存概念伪装成已实现。
4. **虚假验收风险**：已禁止用服务端 TTS yield 代替浏览器播放，禁止用 mock/历史5.08秒单样本代替真实30条，禁止缺失浏览器确认的样本进入完整分位数。
5. **资源风险**：指标仅保留有限条脱敏数字记录；不会引入模型常驻或明显内存负担。

## 已闭环意见

| 编号 | 严重度 | 意见 | 闭环方式 |
|---|---|---|---|
| O1-A-01 | P1 | 当前前端 `MediaSession` 是占位，服务端首包不能证明用户听到 | 将浏览器 PCM 非静音检测与播放确认列为 O1 必做和硬验收 |
| O1-A-02 | P1 | WS 当前生成期间不读取客户端控制帧，确认处理可能延后 | 回传携带浏览器测得的相对耗时；服务端处理时不得用接收时刻替代 |
| O1-A-03 | P1 | 旧轮确认可能污染新轮 | 接受前校验 trace、turn、generation；重复/旧确认拒绝计入 |

| O1-A-05 | P2 | O1 基线可能被误写成最终通过 | 文档明确 O1 仅证明计量可信；B2/B2.5 状态保持未通过 |
