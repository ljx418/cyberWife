# B2.5-O3R 验收标准

**日期**：2026-09-25  
**状态**：开发前冻结

| ID | 场景与操作 | 硬门槛 |
|---|---|---|
| O3R-AC-01 | 比对 Windows 源 ASR 与 WSL ext4 副本 | 文件数、逐文件尺寸和SHA256 100%一致；源文件保留 |
| O3R-AC-02 | 连续3次从ext4冷启动 Speech Worker 并真实转写 | 3/3 ready且产生非空转写；`incomplete`/读取错误=0 |
| O3R-AC-03 | 预热后连续30条普通问题真实Edge全链 | 30/30浏览器确认非静音；P95≤7000ms；P50如实报告但不设硬门 |
| O3R-AC-04 | 检查质量与资源 | 默认TTS CER≤5%；项目RAM≤14GB、VRAM≤22GB、宿主/WSL可用均≥2GB，无持续swap-in |
| O3R-AC-05 | 恢复原注册路径并再切回ext4 | 两次均可启动、设置和会话数据不变、无需下载 |
| O3R-AC-06 | 回归与证据完整性 | 后端无新增失败、前端build通过；原始样本、命令、哈希和日志齐全 |

判定规则：任一硬门失败则O3R失败。CosyVoice A/B只有在Qwen未达O3R-AC-03时才执行，且不得使用已拒绝的TensorRT profile充当候选。
