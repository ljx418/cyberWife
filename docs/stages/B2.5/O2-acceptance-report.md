## 4. 原资源阻断与关闭

项目RAM 11.658GiB≤14、VRAM 12.459GiB≤22、WSL可用约9.4GiB、pswpin=0；但 Windows Available 在60秒空闲复采为1124～1257MiB。清理本轮泄漏的15个测试页、只保留一个Edge页面后为1712MiB，仍低于2048MiB硬门。

该失败可能与当前机器额外约2.35GiB用户Chrome和WSL长期开发提交有关，但不能通过终止用户进程或降低门槛消除。需要在“启动前约16GiB可用”的目标基线重新启动本项目并复跑资源门；未满足前不得进入O3 TensorRT构建/加载。

资源恢复后复测仍发现宿主余量不足，故按规则回到O2R计划。最终选中llama.cpp `--no-host`：30/30，P50/P95=5.913/7.827秒，Windows Available六次最小2832MiB且空闲自然回收后连续18次≥3372MiB；项目RAM约10.6GiB、VRAM约11.7GiB、WSL Available约9.8GiB、swap-in=0。`O2-RAM-01`已关闭，详见`O2R-acceptance-report.md`。
