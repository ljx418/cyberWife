# B2.5-O1 可观测性基线验收标准

**日期**：2026-09-25  
**状态**：开发前门禁已锁定

| ID | 场景与步骤 | 证据 | 出门门槛 |
|---|---|---|---|
| O1-AC-01 | 用固定普通语料完成一轮真实 ASR→LLM→TTS→浏览器播放 | 单轮脱敏 JSON | 四个时间点齐全且严格单调；标识一致 |
| O1-AC-02 | 同一构建预热后连续执行30条普通语料 | CSV、汇总 JSON、运行命令 | 30/30 完整、非空；输出 P50/P95 与各阶段耗时 |
| O1-AC-03 | 发送静音帧后再发送有效 PCM | 浏览器测试记录 | 静音不确认；首个非静音只确认一次 |
| O1-AC-04 | 重复确认、未知 trace、旧 generation 确认 | 合同/集成测试 | 全部拒绝计入；不得覆盖新轮样本 |
| O1-AC-05 | 查询 normal/cache-hit/config-invalid | 指标快照 | 三桶独立；O1 后两桶样本数为0 |
| O1-AC-06 | 跑既有完整后端测试与前端构建 | 测试日志 | 无新增失败；WS 六字段 envelope 不变 |
| O1-AC-07 | 对比未接入计量的既有 B2 数据与 O1 30条 | 原始样本与统计 | 无算法、模型、调度阈值变化；计量自身不制造伪改善 |
| O1-AC-08 | 30条期间采集资源和队列 | 资源 CSV/JSON | VRAM≤22GB；项目RAM≤14GB；两侧可用≥2GB；无持续swap-in/队列增长 |
| O1-AC-09 | 检查证据和运行指标内容 | 隐私扫描结果 | 不含对话原文、音频、人设、记忆、绝对资产路径 |

## 判定规则

- O1-AC-01～09 全部 PASS 才允许进入 O2。
- 本文为当时冻结的历史门槛；2026-09-25 G-LAT7已将最终普通首响改为P95≤7.0s、P50仅报告。O1可以如实记录基线，但不得据此把B2或B2.5写成已通过。
- 真实模型或浏览器无法执行时，只能标记 `BLOCKED`，不得用 mock、服务端 yield 时间或历史单样本代替。
