# B2.5-O2 低风险流水线优化验收标准

**日期**：2026-09-25  
**状态**：开发前门禁已锁定

| ID | 场景/操作 | 出门门槛 |
|---|---|---|
| O2-AC-01 | 默认不开启任何O2候选启动 | 行为与O1一致；无隐式默认变化 |
| O2-AC-02 | L1单slot 10条筛选/必要时30条 | 标识完整；按5%收益/3%回退规则决定，不以单样本晋级 |
| O2-AC-03 | L2关闭连续批处理10条筛选/必要时30条 | 与L1相同，且只改L2变量 |
| O2-AC-04 | S1 8字首片10条筛选/必要时30条 | 延迟规则达门；全文无丢字/重复；CER≤5%；盲听不回退 |
| O2-AC-05 | 组合已通过的单变量并复跑30条 | 组合收益可重复；任何抵消即拆除该变量 |
| O2-AC-06 | 每个候选回滚到O1配置 | 无数据迁移；一轮启动内恢复；30条基线可复现 |
| O2-AC-07 | 后端全回归、前端构建、Edge合同 | 无新增失败；generation/浏览器确认不回退 |
| O2-AC-08 | 每个30条候选采集资源 | RAM/VRAM/可用内存/swap/队列全部达门 |
| O2-AC-09 | PRD和证据审查 | 普通与未来缓存桶不混合；P0/P1=0 |

O2不要求单独满足最终首响门；它要求安全完成低成本搜索并只保留有重复收益的配置。本文原2.0/3.5秒门槛已由2026-09-25 G-LAT7的P95≤7.0秒取代，O2历史结论不变。
