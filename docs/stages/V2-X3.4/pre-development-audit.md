# V2-X3.4 开发前审计

**结论：CONDITIONAL PASS。** 允许实现生成与注册工具并产生候选；人工视觉门通过前禁止激活第二外观，也禁止签署 X3.4 完成。

## 已闭环风险

- **错误人物混合**：三张测试图片是不同人物；实现只读取 source-pack 中当前批准源 SHA。
- **双人物/遮罩回退**：关键帧和 Idle 均直接生成完整场景，MuseTalk 处理同一完整视频帧，不创建浏览器叠加人物。
- **资源冲突**：离线生成负责串行停用实时 Avatar、Speech 和 LLM，finally 恢复；禁止两套 Avatar 引擎双常驻。
- **虚假批准**：机器门只签结构、动作、哈希、音频响应和资源；身份保持、服装正确、光影融合及自然度留给用户。
- **影响当前体验**：未批准候选使用独立目录，现有活动 manifest 和绑定不可变。

## 剩余受控风险

生成式换装可能改变脸部细节或服装图案，并可能在动作帧中漂移。该风险无法只靠自动指标消除，因此以 HTML 逐场景对比和人工批准作为强制门；失败时回到提示词/seed，不进入 X3.5。
