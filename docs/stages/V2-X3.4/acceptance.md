# V2-X3.4 验收标准

| ID | 用户操作/验证 | 硬门 |
|---|---|---|
| X3.4-AC01 | 核对人物与来源 | 只引用当前已批准人物源；其他人物混入为 0；授权、SHA、provenance 完整 |
| X3.4-AC02 | 查看第二外观三个场景关键帧 | 1536×864、单人、正脸半身、闭嘴、蓝白碎花上衣、完整场景直接生成 |
| X3.4-AC03 | 每段 Idle 循环 5 次 | ≥10 秒、无黑帧、首尾 MAE≤3、脸中心 P95≤2.5%、脸面积 CV≤3% |
| X3.4-AC04 | 用固定真实音频生成口播 | MuseTalk 嘴部实际响应音频；单人物、同背景、无额外图层、无冻结 |
| X3.4-AC05 | 检查资产链 | appearance/source/rendition ID、SHA、模型、提示词、seed、场景引用和回滚清单完整 |
| X3.4-AC06 | 故障注入 | 缺文件、哈希错、多脸、超动作或不兼容数据集均不得注册或激活 |
| X3.4-AC07 | 资源与隐私 | 无外联上传；重型模型不双常驻；RAM/VRAM 不突破本机门槛 |
| X3.4-AC08 | 人工观看 HTML 对比页 | 身份、服装、正脸、背景光影、Idle 与口播自然度全部确认后才标记 `confirmed=true` |
| X3.4-AC09 | 全量回归 | 后端、前端、Avatar 和现有四场景切换无新增失败 |

AC01～07/09 可自动签署；AC08 是不可由机器代签的高风险体验门。
