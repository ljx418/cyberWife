# V2-X3.4-R1 开发计划：MuseTalk嘴部时序稳定性

## 问题

项目所有者已确认第二外观服装可用，但三段口播仍可感知嘴部抖动。当前MuseTalk逐帧生成并直接空间融合，没有嘴部时序稳定；16fps底片重采样到25fps后，融合区域的微小差异可能形成高频二阶运动。

## 实施范围

1. 先验证输出像素域自适应EMA；若产生黏滞/冻结则明确否决并回退。
2. 再验证Whisper条件特征EMA；若收益不足或仍产生冻结则明确否决并回退。
3. 推荐路径针对已通过低幅门的正脸Idle，在构建MuseTalk数据集时使用全段中位数固定脸框；不平滑音频条件或输出像素。
4. 能力在avatar manifest记录`coordinate_stabilization=median`；当前红色正式形象保留原逐帧脸框，只对蓝白碎花候选做A/B。
5. 使用同一8秒真实PCM逐场景重采集，比较嘴部/脸部一阶与二阶运动、音频响应、冻结、黑帧、首帧与推理fps。

## 回滚

选择原始逐帧坐标数据集即可回到原MuseTalk路径；不修改模型权重、Idle素材、活动数据库和场景绑定。输出像素域EMA与音频特征EMA均因连续近冻结达到3帧而撤销。
