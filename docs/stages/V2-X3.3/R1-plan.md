# V2-X3.3-R1 质量修订计划：动作节奏与嘴部融合

## 触发证据

项目所有者审查三个真实场景口播后确认：口型响应已有明显改善，但人物动作帧间不协调、连续性不足，嘴部两侧脸部轮廓羽化过宽。因此X3.3-AC06不通过，X3.3退回质量修订；不得以既有嘴部运动比替代人工自然度结论。

## 根因假设与最小改动

1. 现有Idle为16fps、160帧，实时输出为25fps；运行时每个输出帧直接前进一张源图，底层动作等效加速1.5625倍。构建器新增面向25fps运行时的确定性时间重采样，扩大可用取帧序列到250帧并保持10秒时长。
2. 现有lower-face掩膜在整张下半脸横向融合，水平边界羽化约为脸框短边5.5%。候选改为椭圆形口周/下颌关注区，并缩窄边缘过渡，避免把脸颊轮廓大面积纳入生成层。
3. 不修改ASR、LLM、TTS、H.264传输、浏览器单画布和场景激活架构；候选使用新build revision和新avatar id，原工件保留可回退。

## 执行顺序

1. 扩展数据集清单，记录原始fps/帧数、运行fps/帧数、时间重采样模式和融合profile。
2. 运行时按数据集profile选择融合方式，旧清单继续使用兼容模式。
3. 新增动作节奏、帧间二阶跳变和脸框边缘扰动质量门；门只量化连续性/边界稳定性，不冒充口型语义自然度。
4. 用同一当前人物、同一场景、同一真实CosyVoice音频分别采集baseline与candidate；自动指标改善且无黑帧/FPS/嘴部响应回退后，才生成新人工审查视频。
5. 候选未获人工批准前不得写活动场景绑定。其他形象的口播验证保留在X3.4外观动态素材及X3.5组合预设阶段。
