# V2-X3.3 开发前 PRD 检视

## 结论

范围与V2-R01、V2-R03及V2X-AC03一致，并保持V1单人物实时对话不变量。

## 规格映射

- “多个背景”落实为四个已批准完整场景，而非人物层叠加静态背景。
- “切换时不中断会话”定义为保留同一conversation session、turn序列、麦克风和音频链；允许Avatar传输在同场景Idle遮挡下短暂重连。
- “跨重启保留”由SourcePack的`active_scene_id`承担，不以浏览器localStorage作为事实源。
- “错误素材泄漏为0”由scene/rendition/binding三方SHA交叉验证和单人物数据集验证承担。

## 不越界声明

本阶段不承诺多形象、多空间CRUD、任意文本场景生成或运行时换装；这些分别属于X3.4/X3.5或V2-A。X3.3完成也不等于V2X-AC03最终完成，后者还需X3.4/X3.5的两外观组合证据。
