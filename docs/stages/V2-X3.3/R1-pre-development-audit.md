# V2-X3.3-R1 开发前审计

## 结论

**PASS，可进入受控A/B实现。** 本轮只修正X3.3现有Wav2Lip数据准备和融合profile，不提前实施X8高清模型升级，也不把其他形象纳入当前人工门。

## 风险闭环

| 风险 | 等级 | 闭环方式 | 状态 |
|---|---:|---|---|
| 重采样产生重影或身份漂移 | P1 | 同时检查清晰度/边缘能量，候选独立ID，不覆盖baseline | CLOSED FOR ENTRY |
| 收窄掩膜导致嘴角接缝 | P1 | 采用椭圆软掩膜而非硬裁切；边界环与口周响应双门 | CLOSED FOR ENTRY |
| 指标优化但主观更差 | P1 | AC06保留人工A/B硬门，未批准不激活 | CLOSED FOR ENTRY |
| 误改全部旧人物 | P1 | profile由manifest显式选择；缺失时维持旧lower模式 | CLOSED FOR ENTRY |
| 越权扩张到多形象 | P2 | 多形象口播按既定X3.4/X3.5验收，不在R1执行 | CLOSED FOR ENTRY |

## 语义与架构一致性

- “增加取帧范围”在本轮落实为把10秒源动作覆盖到完整250个25fps输出时刻，而非加速遍历160张源图。
- “质量控制门”只声称可重复量化的节奏、连续性、边界扰动、清晰度、嘴部响应与性能；音素正确性和自然观感仍由人类判断。
- 保留完整场景单画布、当前人物和本地闭环，不新增图层、在线调用或常驻模型。
