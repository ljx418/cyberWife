# V2-X3.3-R1 验收标准

| ID | 验证动作 | 出门门槛 |
|---|---|---|
| R1-AC01 | 检查候选数据集 | 10秒素材按25fps提供250帧；时长误差≤40ms；完整场景、单人脸、无黑帧；原数据集未覆盖 |
| R1-AC02 | 同音频采集baseline/candidate | 两者输入WAV、场景、人物、输出25fps一致；candidate无黑帧、序列缺口或传输丢帧；近似重复帧占比必须披露，最长连续≤2对（80ms），超过即视为持续冻结；禁止以加噪声消除重复帧 |
| R1-AC03 | 动作连续性 | candidate的源动作速率恢复为1.00±0.02倍；帧间运动二阶跳变P95不高于baseline，且不得以全局模糊换取低分 |
| R1-AC04 | 融合边界 | 脸框左右边界环相对源帧扰动扣除相邻H.264控制带噪声底后，净扰动P95较baseline下降至少20%；嘴部有声/静音运动比仍>1.10 |
| R1-AC05 | 性能与资源 | inferfps/finalfps均≥25、backlog≤3、传输丢帧0；不新增常驻模型或突破既有硬件门 |
| R1-AC06 | 人工观看同音频A/B | 动作协调性与脸颊轮廓至少不差于baseline，且项目所有者明确批准；机器门不得代签 |
| R1-AC07 | 回归与PRD检视 | Avatar单测、根测试、前端测试/构建通过；单人物、完整场景、同会话切换合同不回退 |

R1-AC01～05与07由自动化签署；R1-AC06必须由项目所有者签署。若自动门未改善，保留旧工件并停止，不激活候选。
