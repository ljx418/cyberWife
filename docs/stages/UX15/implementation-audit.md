## 白盒结论

- 循环Idle使用稳定URL与稳定DOM节点，不再因Intro/Outro phase更换而卸载。
- Intro/Outro是独立叠加层，只有媒体就绪后才淡入；失败时移除叠加层，循环Idle仍在。
- Canvas从live退出时先令Idle接管，最后帧保留260ms覆盖CSS淡出窗口，再清理像素。
- 新live帧会取消延迟清理，避免快速重连把新画面误清空。
- portrait/stale ID失败关闭逻辑未放宽；语音失败降级边界未改变。
