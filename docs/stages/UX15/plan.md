# UX15 开发计划：会话切换无闪动

**日期**：2026-10-07
**范围**：V1人工总验收前的最后一项显示连续性修补；不更换Avatar模型，不提高硬件门槛。

## 用户场景与目标

用户在完整场景Idle上点击“开始对话”或“结束对话”时，画面必须始终由同一人物、同一背景的一张可用帧覆盖。不得因视频URL换源、Canvas清空或Outro尚未解码而短暂露出黑帧、静态背景、旧写真或第二人物。

## 实施实体

1. `App.tsx`把稳定循环Idle与一次性Intro/Outro拆成两个常驻/叠加媒体层；切换序列时不卸载循环Idle。
2. 一次性序列仅在`playing/canplay`后淡入，结束或失败时回到已就绪循环Idle。
3. `AvatarSession`退出live时先切换层状态，保留最后Canvas帧覆盖淡出窗口，再延迟清理；取消生成时也回退Idle。
4. CSS确保`Idle → live → Idle/Outro`只发生同场景交叉淡化；portrait/stale画布继续失败关闭。

## 风险与停线条件

- 任何时刻所有场景媒体层透明度均为0，FAIL。
- 同屏出现两个可辨人物、矩形遮罩、黑帧或静态写真跳变，FAIL。
- Intro/Outro加载失败不得阻断对话；必须保留循环Idle。
- V1不以本修补承诺更高分辨率或更自然口型；两项进入V2-X质量优化。
