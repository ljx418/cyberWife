# V2-X3.4-R2 验收标准

| ID | 场景 | 操作 | 硬门 |
|---|---|---|---|
| R2-AC01 | PCM 状态分类 | 注入有声、短静音、持续静音与显式完成 | 有声立即进入；短静音有界保持；持续静音切 Idle；complete 不丢弃已排队有声帧 |
| R2-AC02 | 批内状态隔离 | 同一批含有声与静音视频帧 | 只对有声帧使用模型输出，静音帧使用 Idle，不因单个有声帧污染整批 |
| R2-AC03 | generation 收尾 | 正常 TTS、缓存回复和直接采集各完成一次 | 正常结束调用 complete；取消只调用 cancel；新一轮 generation 不继承旧尾音 |
| R2-AC04 | 三场景真实 PCM | 相同 8 秒输入实时注入 | 黑帧0、序列无缺口、有声段最大连续近冻结≤2、音频响应比≥1.10；Idle静止由R2-AC05独立约束 |
| R2-AC05 | 末段硬门 | 检测最后有效语音后至少400ms静音 | 末段嘴部差异/有声差异≤0.78；末段不出现高于有声段的持续二阶抖动 |
| R2-AC06 | 时长与性能 | 检查封装和运行指标 | 主证据音视频时长差≤80ms；首视频包≤7秒；推理FPS≥25；24GiB显存不突破 |
| R2-AC07 | 回归 | 全量自动测试 | Avatar、后端、根级、前端构建及Playwright全绿 |
| R2-AC08 | 人工A/B | 项目所有者观看三场景末段 | 语音结束后自然闭嘴并回Idle，无末段抖动、错音或突变 |

R2-AC08 不可由自动指标代签。
