# V2-X3.4-R2 开发前审计

**结论：PASS，可实施。新增致命/重大规格偏差：0。**

- 发现属于状态协议和测试覆盖缺陷，不要求替换模型，架构冲击限定在 Avatar PCM 合同、Gateway 适配器与验收工具。
- complete 与 cancel 语义分离：正常完成只排空右上下文并切 Idle；打断继续原子清空旧 generation。
- 低能量分类仅控制 Avatar 是否采用生成脸，不修改浏览器实际播放 PCM，避免吞字或声音回退。
- 逐帧选择复用已经算出的批推理结果，不改变模型批大小、权重、显存驻留和 25 FPS 输出合同。
- 验收主视频严格按输入时长，但必须同时通过产品态末段运动门；禁止用裁剪隐藏 6.9～8.0 秒的真实尾静音缺陷。
- 人工门继续保留，自动测试不得签署主观自然度。

## 实施中审计补充

旧冻结门统计全片嘴部静止，会把语音结束后自然闭嘴的 Idle 反向判为失败。R2 将“持续冻结”限定在有声区间；全片冻结数继续报告，末段由嘴部差异衰减和二阶抖动两道门独立约束。这是修复互相冲突的验收语义，不是降低有声口型门槛。
