# ARCH1 PRD规格检视

| PRD/架构条目 | 影响 | 偏移判断 |
|---|---|---|
| NFR-07 单向依赖 | 直接关闭已知反向依赖 | 对齐 |
| FR-04/05/11 资产管理 | 只改变依赖注入，不改API/数据 | 无体验偏移 |
| FR-08/09/10 对话媒体 | 只注入日志与指标端口 | 无状态机/时序偏移 |
| FR-12/14 审计与保留 | 审计SQL下沉到仓储 | 返回字段与限制不变 |
| NFR-04/06 隐私可观测 | 日志实现仍在Infrastructure，由组合根注入 | 边界增强 |

结论：ARCH1是目标架构缺口修复，不新增或删减PRD功能，不需要重新开启G-UX。
