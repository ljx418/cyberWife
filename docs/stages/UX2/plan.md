# UX2 实施计划：闭嘴微动底片与嘴型融合

## 用户结果

写真激活后生成约 5 秒、可无缝往返循环的闭嘴微动底片；空闲时有呼吸、眨眼和极小幅头部动作，说话时只在稳定的人脸区域叠加嘴型。停止或异常时回到写真，不显示黑帧。

## 实施顺序

1. 固化 Wan2.2 I2V 工作流与模型保留合同，提示词严格禁止说话、张嘴和大幅运镜。
2. 增加视频到 Wav2Lip 数据集的离线构建器；逐帧检测、框平滑、首尾运动约束和源 SHA 清单。
3. 改造 Wav2Lip 合成：保留眼镜和上半脸，只对下半脸使用羽化遮罩；开启受控过渡。
4. 以当前真实写真和真实短视频完成数据集构建、空闲循环与口播回归。

## 资源边界

- Wan2.2 只在人物设置/预热阶段运行，与 LLM、ASR、TTS、Avatar 实时进程互斥。
- 生成失败不破坏已激活静态 Avatar；实时会话仍受 RAM≤14GiB、VRAM≤22GiB 门槛约束。
- 不在实时对话中加载 Wan2.2 或 InsightFace 全套 Python 依赖。

## 不做


- 不把随机生成视频直接当成已验收数据。
- 不默认切换到尚无权重与真实 A/B 证据的 MuseTalk。
- 不用“整张照片缩放/平移”冒充生成式待机动作。
