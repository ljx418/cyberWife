# UX2 开发后审计

结论：代码与数据链路无 P0/P1；首个候选已由用户人工签署并完成运行时激活。多写真验证暴露的姿态/遮挡漂移作为后续质量门改进项，不阻塞当前已签署候选。

- Wan 仅在实时栈停止后执行；生成后 ComfyUI 已停止，实时栈恢复，全组件 ready。
- 运行时没有常驻 Wan/UMT5/VAE，RAM 9.71GiB、VRAM 11.17GiB，未突破 14/22GiB 门槛。
- 视频构建器拒绝多脸、时长/FPS越界、检测框突跳、源 SHA 不一致和未视觉批准的升级。
- Wav2Lip 只羽化下半脸，保留眼镜/上半脸；说话/静止切换使用 120ms 过渡；水印默认关闭。
- 2026-10-05 用户明确批准首个候选；原子升级后 Windows Chrome 动态解码探针通过，运行时读取 81 帧而非静态单帧。
- 三张额外写真均技术构建通过，但手势保持、侧脸姿态保持和新物体抑制不能仅靠“检测到一张脸”证明，详见 `multi-portrait-validation.md`。
