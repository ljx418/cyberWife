# V2-X3.2 开发前审计

**结论**：CONDITIONAL PASS；允许实现和生成候选，但人工视觉批准前不得进入X3.3。

- 采用完整场景直接生成，与用户否决的抠图/羽化路线无冲突。
- 身份参考、背景参考、输出和manifest均在私有本机目录；生产执行器只访问loopback ComfyUI。
- Qwen与Wan串行，且生成时暂停实时模型，符合16GB空闲内存/24GB显存边界。
- 自动门能拒绝结构、黑帧、接缝、多人脸和超动作，但不能证明“像本人”或“自然”；AC06保留人工门。
- 本阶段不注册active rendition，不会导致说话时背景跳变。
- 使用宿主imagegen生成的三张图仅作提示词/构图预研，不具备本机离线来源资格，不得直接签入X3.2正式产物；正式候选必须由新增本机工作流重建。
