# V2-X3.2 开发计划：场景动态素材

## 用户结果

为清晨卧室、雨夜书房、花园阳光房各得到一套同一人物、同一红色外观、正脸半身、背景一次成像的10秒低幅Idle候选；与既有蓝调客厅共同形成四场景素材基础。

## 实现范围

1. 新增本机Qwen Image 2.1双参考工作流：当前授权人物为身份/外观参考，登记背景为场景参考，直接生成完整场景关键帧。
2. 新增可复现执行器，串行生成三张16:9关键帧，记录模型、工作流、输入、提示词、seed和输出SHA。
3. 复用本机Wan 2.2首尾同帧工作流生成3段10秒/16fps低幅Idle，背景、人物、光影作为完整画面共同生成。
4. 自动检查单人脸、正脸可用区域、分辨率、帧数、fps、黑帧、首尾缝和动作幅度。
5. 产物只进入私有验收目录；人工批准前不写rendition、不生成可激活绑定、不影响当前舞台。

## 明确不做

- 不使用抠图、透明通道、发丝羽化或浏览器双图层。
- 不改变当前活动Avatar或`active_scene_id`。
- 不以自动分数代签人物身份、光影融合和动作自然度。

## 资源与回滚

Qwen与Wan串行运行，生成时暂停LLM/Speech/Avatar并在finally恢复；不允许双模型常驻。失败保留上一可用V1场景，不安装候选。
