# V2-X2 开发计划：沉浸式构图

## 用户结果

用户可为当前人物选择近景、半身或全身构图；1920×1080、2160×3500、3840×180和420×720都有明确舞台策略。人物焦点与主操作保持可见，背景始终填满舞台，偏好刷新后保留。

## 实现范围

1. 新增纯函数`StagePresentationController`，统一视口分类、请求构图、有效构图、焦点和降级原因。
2. 复用现有单舞台、单人物和`avatarFocus`；只输出展示元数据/CSS变量，不复制会话或Avatar状态。
3. 近景、半身、全身分别调整人物占幅与object-fit；完整场景视频继续占据同一个主舞台。
4. 3840×180条幅明确降级为近景，保住脸和主操作；界面显示降级说明而非假装展示全身。
5. 背景层始终cover，人物层可contain；不以纯色填补裸露区域。
6. 构图偏好仅写现有浏览器本地偏好边界，feature flag关闭即回到V1默认构图。

## 不做

- 不裁切或生成新照片/视频，不改变人物身份与场景素材。
- 不移动对话业务状态、口型时钟或A/V层级。
- 不承诺在180px高条幅中同时完整展示全身与全部文案。

## 交付实体

- `prototype/src/services/StagePresentation.ts`
- 主舞台data/CSS变量与设置页构图控制
- 四视口与偏好/降级Playwright用例
- feature flag、构建产物、阶段审计和架构同步

## 回滚

关闭`features.stage_composition`后忽略已存偏好并使用既有V1布局；localStorage值保留但不影响页面。
