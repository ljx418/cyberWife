# V2-X2 验收标准

| ID | 操作 | 硬门 |
|---|---|---|
| X2-AC01 | 选择近景/半身/全身并刷新 | 请求构图可逆、偏好保留；不重置会话或人物 |
| X2-AC02 | 1920×1080逐一切换 | 背景无空白，人物层在舞台内，主控制可达 |
| X2-AC03 | 2160×3500与420×720逐一切换 | 人物焦点和主控制可达，无横向溢出 |
| X2-AC04 | 3840×180请求全身 | 明确降级近景并给出原因；脸/主操作优先，无裸露空白 |
| X2-AC05 | Idle→说话→Idle/打断 | 同一人物、同一舞台；构图不创建第二媒体层或重置A/V时钟 |
| X2-AC06 | feature flag关闭 | 控制隐藏、V1默认布局等价 |
| X2-AC07 | 全量回归 | build/Playwright/后端无新增失败 |

人脸真实安全区仍需在最终同一真人素材截图上检查；自动化以DOM边界、无溢出、单人物层和状态不变为硬证据。
