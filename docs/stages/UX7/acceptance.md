# UX7 验收标准

| ID | 用户场景与操作 | 证据 | 出门门槛 |
|---|---|---|---|
| UX7-AC01 | 说三条普通话短句并查看转写 | 原始 WAV/PCM、接口结果、耗时 | 3/3 非空；稳定使用简体字；已知文本关键语义正确；ASR 耗时不造成首响 >7s |
| UX7-AC02 | 回复含两个自然句，完整播放 | TTS 调用记录、WAV、日志 | 每轮 CosyVoice 调用次数=1；输入为完整最终回复；无“过短片段”拆分 |
| UX7-AC03 | 从说话到首个非静音音频 | 真实端到端事件时间线 | 有效样本首响 ≤7s；文本 final、音频 complete 各一次 |
| UX7-AC04 | 播放中说话并打断 | WebSocket 事件与时间线 | 旧 generation 不再产生音频；打断确认 ≤400ms |
| UX7-AC05 | 正常轮、缓存问候、TTS/Avatar 故障降级 | 自动化回归与真实健康检查 | 缓存合同不变；故障仍有文字结果；无黑屏/崩溃 |
| UX7-AC06 | 用户试听优化后多轮对话 | 人工评价 | 用户确认普通话显示可接受且口播连贯度改善 |

## 防虚假验收

1. 单元测试参数命中不能替代至少一条真实模型 ASR。
2. WAV 存在不能证明整句合成，必须记录同轮 TTS 调用次数与输入文本。
3. 机器波形指标不能替代 AC06 主观听感。
4. 首响只计算真实非缓存正常轮；缓存轮单列，不混入正常轮统计。
