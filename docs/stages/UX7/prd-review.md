# UX7 PRD 规格检视

| PRD 条目 | 当前偏差 | UX7 处置 |
|---|---|---|
| FR-08 连续本机语音对话 | 普通话出现繁体/粤语风格字形，回复口播断裂 | 普通话简体解码约束 + 每回复一次 CosyVoice 推理 |
| FR-10 音画同步与降级 | 句间重起韵律会同时造成嘴部驱动停顿 | 保持连续 PCM 时钟，整句流式输出给 Avatar |
| NFR-01 首响与打断 | 既批准首响放宽至 7 秒；打断门不变 | AC03 ≤7s、AC04 ≤400ms |
| NFR-02 本机资源 | 不允许新增常驻模型 | 复用现有 Faster-Whisper/CosyVoice 进程 |
| NFR-04 本机隐私 | 音频不得上传 | 无新公网调用与云端依赖 |

**审查结论**：本计划是既有 FR-08/FR-10 的体验纠偏，不新增 PRD 功能。整句合成以已批准的 7 秒首响预算换取连贯度，语义与架构不存在冲突。

**实现后复核**：真实全链路首个非静音音频 4.766 秒，未突破 7 秒；ASR 三条真实模型样本语义保持正确；整句 CosyVoice 单调用已由代码记录和运行日志双证据确认。自动化规格门全绿，实际麦克风与主观连贯度留给用户验收，不作虚假签署。
