# UX4 实施计划：照片到动态人物的产品化工作流

## 用户结果

用户在首次引导内完成“授权照片 → 裁切 → 正面标准照 → 10 秒无缝 Idle → 人工预览 → 启用 → 实时口型”，无需手工打开 ComfyUI 或修改工作流。未经确认的生成物不能替换当前人物。

## 实施顺序

1. 固化已获人工认可的 Qwen Image 2.1 正面化与 Wan 2.2 严格 Idle 工作流。
2. 新增文件持久化任务状态和私有预览 API；同一时刻只允许一个生成任务。
3. 编排 GPU 互斥：只停止生成前健康的实时组件，ComfyUI 独占推理，最终逐项恢复。
4. 生成 81 帧 16fps 源片，以回文闭环扩展为 160 帧/10 秒，并量化首尾接缝。
5. 在首次引导中提供进度、正面图、循环视频和显式确认按钮。
6. 以真实授权图片执行生产编排复验，再运行接口、UI、离线和既有 Avatar 回归。

## 不变量

- 不提高实时运行的 16 GiB 空闲内存预算；生成属于互斥的离线准备阶段。
- Gateway 保持在线；LLM、Speech、Avatar 只在生成期间释放。
- ComfyUI 仅监听 `127.0.0.1`，Manager 使用任务独立目录和 offline 模式。
- 生成失败、浏览器关闭或未确认时，当前活动人物保持不变。
- Wav2Lip ResearchOnly 的非商业边界不变。
