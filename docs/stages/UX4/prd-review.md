# UX4 PRD 规格检视

**结论：本次是既有“授权人物素材、待机画面、实时口型、本地处理”的实现完善，没有扩张 V1 产品边界。**

- 对齐：首次引导的人物步骤、素材版本化、active 指针、Idle/Speaking 状态、故障保留人物、本地隐私。
- 新增的正面化和视频生成属于首次准备流程，不承诺实时生成，也不改变实时对话 7 秒首响门。
- 10 秒 Idle 只在 `idle/listening/thinking` 作为底片；Speaking 仍由 Wav2Lip 音频驱动，不能用 Idle 视频冒充口型同步证据。
- 用户必须拥有照片授权；生成素材不进入仓库，不引入云服务、多用户、桌面壳或商业发布。
- 资源策略不改变 16 GiB 空闲内存目标：大模型不并存，生成期间实时对话显式不可用。
