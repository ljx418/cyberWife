# UX4 验收门

| 用例 | 用户操作/故障 | 出门门槛 |
|---|---|---|
| UX4-AC01 引导闭环 | 上传照片、生成、查看双预览、确认 | 请求与状态可追踪；确认前 active 不变，确认后同源 Avatar 原子激活 |
| UX4-AC02 视频闭环 | 播放候选视频并反复循环 | 160 帧、16fps、10 秒；首尾 MAE≤3；无黑帧 |
| UX4-AC03 资源互斥 | 四服务健康时发起真实生成 | Gateway 持续在线；只暂停三个 GPU 服务；结束后四服务全部健康 |
| UX4-AC04 失败安全 | 缺模型、8188 占用、生成失败或未确认 | 停止前预检；旧人物不变；错误可见；原在线服务恢复 |
| UX4-AC05 本地边界 | 白盒扫描与 Comfy 日志审查 | 运行入口只用 loopback；Manager=`offline`；无上传动作与外部 URL 请求 |
| UX4-AC06 身份与视觉 | 人工查看正面照和 Idle | 人物、服饰、眼镜等关键身份一致；背景固定；闭嘴、轻呼吸/眨眼，无说话嘴型 |
| UX4-AC07 检查点 | 恢复阶段超时后对同源任务重试 | 校验 source SHA、帧数和接缝后复用生成物，不重复执行模型推理 |
| UX4-AC08 回归 | 后端、构建、Playwright、Avatar builder | 新增路径通过且原对话、打断、黑屏回退、无障碍用例无回退 |

UX4-AC06 只能由人类签署；自动指标不能替代身份与自然度判断。
