# V2-X8.0-R1 验收标准

| ID | 用户场景与操作 | 硬门 |
|---|---|---|
| AC01 | 依次选择四个已批准场景并开始说话 | 每个绑定均声明`engine=musetalk`，数据集250帧/768×432/25fps，人物与场景不串位 |
| AC02 | 每个场景输入同一段真实8秒CosyVoice音频 | finalfps≥25；黑帧、序列缺口、持续冻结、双人物均为0；嘴部实际响应音频 |
| AC03 | 完整栈运行MuseTalk并采集资源 | VRAM≤24GiB、服务/WSL聚合RAM≤16GiB预算；Wav2Lip与MuseTalk进程不得同时常驻 |
| AC04 | 从零启动、状态查询、Avatar恢复 | 默认健康端点报告`engine=musetalk`和正确logical ID；恢复后活动场景一致 |
| AC05 | 强制切回Wav2Lip并再次启动 | 四服务恢复健康、原场景绑定可恢复、用户数据不丢失 |
| AC06 | 代码、PRD与浏览器回归 | 根/后端/Avatar/Playwright相关测试通过；V1首响、打断、声音和会话合同无规格偏移 |

任何场景失败均不得只切换部分绑定；默认继续使用上一获批基线。
