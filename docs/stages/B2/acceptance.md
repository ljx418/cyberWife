# B2 验收标准

**判定**：所有硬门槛均需真实模型证据；mock只用于合同测试，不能替代出门验收。

| 编号 | 用户场景与操作 | 证据 | 出门门槛 |
|---|---|---|---|
| B2-AC01 | 用户完成一句话，角色以授权克隆声音回答 | 30条 `utterance.final→first_audio` CSV、WAV | P95≤7.0s，P50如实报告；30/30非空（G-LAT7于2026-09-25取代原2.0/3.5秒门槛） |
| B2-AC02 | 连续听取短句和多句回复 | TTS RTF、帧序列、试听文件 | 20ms/640字节PCM有序；无句间异常长静音；CER≤5% |
| B2-AC03 | 观察数字人口型 | inferfps/finalfps与音频时间戳CSV、录屏 | inferfps≥25、finalfps≥25；视频迟到不阻塞音频 |
| B2-AC04 | Avatar运行中被终止 | 事件流、连续PCM哈希/帧号 | ≤2s进入静态肖像降级；音频帧连续且文字仍可用 |
| B2-AC05 | Avatar重新启动 | 事件流、健康探针 | 无页面刷新自动恢复，后续音频重新驱动口型 |
| B2-AC06 | TTS不可用 | WS事件与页面合同 | 显式 `text_only`，文本完整，不伪造音频成功 |
| B2-AC07 | 目标硬件完整链路 | RAM/VRAM/swap曲线 | VRAM≤22GB；项目非可回收RAM≤14GB；宿主/WSL可用均≥2GB；无持续swap-in |
| B2-AC08 | 检查隐私与监听 | 端口、日志、文件增量 | 仅loopback；原始音频落盘=0；日志无正文、私有路径 |
| B2-AC09 | 比较Qwen与CosyVoice | 同参考音频/正确逐字稿/同30条文本报告 | 两者均给出可试听样本和完整失败项；只允许满足AC01/02/07者作为默认 |

## 失败回退

- 首响或CER不达标：返回模型调度/适配器开发，不得降低阈值。
- 真实Avatar不足25 FPS：先检查批次、缓存和迟帧策略；仍不达标则停止B2并报告硬件/模型替代路线。
- 资源越界：按分时卸载和缓存降级重测；仍越界则停止，不进入B3。
- 发现音频落盘、非loopback或正文日志：立即清理并停止后续里程碑。
