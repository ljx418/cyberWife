# RES1 详细执行计划：AC-14宿主内存余量闭环

**日期**：2026-10-05

## 目标

在32GiB宿主、约16GiB WSL预算内定位2026-10-04复验中Windows最低可用内存1,840.566MiB的来源，并用现有真实模型组合重跑资源门。不得通过降低2GiB余量、停用V1组件或改用假模型出门。

## 顺序

1. 采集Windows/WSL/GPU当前快照和项目进程清单，区分项目与项目外占用。
2. 校验Launcher/status与采样脚本的单位、时间基准、进程归属和最小值算法。
3. 在不关闭用户进程的前提下，清理项目遗留实例或重复模型进程。
4. 运行预检、真实功能探针和组合资源采样；满足门槛才进入60分钟复验。
5. 若短测无法稳定保留≥2GiB，不启动长测，记录阻断与可选路线。

## 非目标

- 不降低硬门，不减少PRD功能，不以静态文件/端口代替模型功能探针。
- 不结束无法确认归属的Windows进程，不修改系统分页文件或WSL全局配置。
