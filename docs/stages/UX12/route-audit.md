# UX12 路线审计

## 结论

直接生成完整场景的架构改动高于离线抠图，但能消除轮廓、发丝、羽化和光影割裂形成的长期体验债务，批准作为目标路线继续验证。旧抠图链仅保留可回退能力。

## 已识别风险

- 源肖像没有提供下半身；首批全身关键帧的裙装、鞋履和腿部比例属于模型推断，必须标注来源，不能描述为用户真实外观。
- 全身 768×432 视频中的脸部像素较少，Idle 可验证，但不能直接推导口型质量。说话态优先设计同场景中景变体，或在更高分辨率样片通过后再采用全景口型。
- 不同姿势是独立生成，人物身份、服装和场景仍可能轻微漂移；只有通过并排关键帧和视频抽帧审查的变体才能入库。
- 极端竖屏和超宽窗口需要安全区域或独立画幅变体；单一 16:9 视频不能承诺覆盖全部窗口。

## 审计决定

本轮仅交付背景、三类姿势关键帧、三段完整场景 Idle 候选和证据；不修改当前线上 Avatar，不提前承诺 Idle/说话态无缝切换。
