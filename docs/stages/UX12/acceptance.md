# UX12 验收门槛

| ID | 用户场景 | 操作与证据 | 出门门槛 |
|---|---|---|---|
| UX12-AC01 | 用户选择客厅空间 | 查看场景底图及 SHA-256 | 无人物、固定机位、16:9；背景证据可追溯 |
| UX12-AC02 | 用户选择基础姿势 | 查看三张关键帧和接触关系 | 同一人物、同一客厅；沙发/地面接触、遮挡和光影在单张图内成立 |
| UX12-AC03 | 用户观看 Idle | 播放三段真实 Wan 输出并读取 manifest | 每段 10 秒、16 fps、160 帧、无黑帧、首尾 MAE ≤ 3 |
| UX12-AC04 | 用户切换背景/姿势 | 白盒检查工作流与脚本 | 主链无抠图、Alpha 合成、发丝分割和羽化节点 |
| UX12-AC05 | 用户连续观看 | 审查接触表面、背景与光照 | 不得出现明显漂浮、家具漂移、背景呼吸、强制位移或大幅动作 |
| UX12-AC06 | 用户从 Idle 进入说话态 | 架构评估与真实样片验证 | 在口型实测通过前明确标记为未完成，禁止宣称全身说话态已交付 |
| UX12-AC07 | 用户退出生成流程 | 检查服务与私有目录 | 实时服务恢复；生成资产未进入 Git 跟踪 |

自然度与身份一致性仍需人工观感验收；机器指标不能替代该结论。
