# UX12 图像生成提示词包

本轮图像使用内置 ImageGen 生成，用作完整场景路线的视觉基线；视频由本机 ComfyUI/Wan 生成。提示词不把源肖像中不可见的下半身当成事实。

## 场景底图

正向约束：写实摄影、现代舒适客厅、蓝调时刻、右侧米色沙发、落地窗城市夜景、暖色落地灯、木地板和茶几、左侧保留人物活动空间、固定机位、16:9、无人物。

限制：不得出现人物、人体局部、文字、水印、镜面人物、强烈景深模糊、夸张广角和不可解释的光源。

## 人物与场景合成关键帧

共同约束：以身份参考图中的同一成年人为人物，以场景底图为唯一房间；保持脸型、五官、肤色、发型及红色上衣特征；生成全身、黑色长裙与黑色平底鞋；人物必须接受窗外冷光和室内暖光，并在地面或沙发上形成合理接触阴影。完整场景一次生成，不产生透明通道。

- `sofa-upright`：端坐于沙发，双手置于腿上，脚踝交叠，靠垫产生合理压痕。
- `sofa-relaxed`：倚靠沙发靠垫，一侧前臂放在靠垫上，脚踝交叠，遮挡和压痕真实。
- `window-standing`：窗边全身站立，双手轻合，双脚着地，暖色轮廓光与冷色窗光同时成立。

负向约束：不同人物、身份漂移、多人、肢体缺失、额外手指、悬浮、脚底离地、不合理家具穿插、改变房间布局、光向冲突、文字、水印、卡通感。

## 溯源说明

源图只提供上半身外观。长裙、鞋履、下半身比例和姿势是生成模型推断内容，不代表用户真实身体或真实穿着。
