# UX12 完整场景直接生成计划

## 目标

停止把“人物抠像 + 背景预合成”作为目标路线。先生成无人物场景底图，再在同一场景中直接生成包含完整人物、家具接触、遮挡关系、接触阴影和环境光的关键帧，最后由 Wan 2.2 I2V 生成各姿势的闭环 Idle 视频。

## 首批姿势

1. 沙发端坐：双脚/脚踝稳定，双手置于腿上。
2. 沙发放松：身体倚靠靠垫，手臂与靠垫产生明确接触。
3. 窗边站立：双脚着地，双手轻合，人物接受窗外冷光与室内暖光。

## 实现边界

- `ScenePlate`：无人物、固定机位、16:9 场景底图。
- `PoseKeyframe`：完整场景关键帧；人物与场景一次生成，不含透明通道。
- `FullSceneIdleRendition`：按 `scene_id + identity_id + pose_id` 管理的视频变体。
- 主路线禁止轮廓抠图、发丝分割和边缘羽化；旧合成器仅保留兼容回退，不进入目标验收。
- 首批只验证 Idle。说话态需后续采用同场景中景机位或经实测可用的全场景口型数据集，不能把旧半身视频冒充无缝切换。

## 资源与隐私

- 图片与视频只落入仓库忽略的 `assets/private/` 和用户私有验收目录。
- ComfyUI 离线启动；串行生成，运行时暂时停用语音、Avatar、LLM 服务，结束后恢复。
- 目标设备预算沿用 16 GB 空闲系统内存，不并发驻留大模型。
