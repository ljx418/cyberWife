# UX9 验收标准

| 编号 | 用户场景 | 操作与证据 | 出门门槛 |
|---|---|---|---|
| UX9-AC01 | 安静环境开始说话 | 向边界检测器输入普通人声强度序列 | 100ms内进入采集；900ms以内停顿不结束句子 |
| UX9-AC02 | 系统口播时出现风扇、键盘或短促碰撞声 | 输入低幅持续噪声和不满240ms的高幅脉冲 | 不产生`start`，不发送`barge_in.detected` |
| UX9-AC03 | 系统口播时用户持续插话 | 输入达到播放态阈值的持续语音 | 240ms触发；连同现有取消链，静音仍满足P95≤400ms |
| UX9-AC04 | 合成用户语音进入真实主链 | 项目CosyVoice生成输入，真实SpeechRuntime识读 | 每条输入ASR非空；规范化CER≤10%；不得串题 |
| UX9-AC05 | 回复可正确交流 | 问候、事实、安慰、建议、上下文与追问逐项规则评分 | 6/6回答非空、答非所问=0、关键事实错误=0、上下文追问正确 |
| UX9-AC06 | 回复语音可懂且忠于文字 | 收集`reply.audio.chunk`，按时钟重组后送真实Faster-Whisper | 6/6可识读；相对`reply.text.final`规范化CER≤15%；关键答案保留率100% |
| UX9-AC07 | 回复完整有序且首响合规 | 文本与重识读文本做结构检查，并记录首个音频包相对ASR完成的服务端时间 | 无模型标记/乱码/异常重复；一句完整口语、7～14汉字（缓存问候除外）；结尾完整；每条首响≤7秒 |
| UX9-AC08 | 隐私与资源 | 检查报告、文件和运行资源 | 不保存PCM/WAV、参考音色或私人路径；仅保存合成文本、指标、哈希；不新增常驻模型 |
| UX9-AC09 | 无回退 | 全量自动回归 | Backend、根工具、Avatar、前端build/Playwright全部通过 |

真实闭环必须使用本机实际Qwen、CosyVoice和Faster-Whisper。Mock只能验证评分器合同，不能签UX9-AC04～07。
