| 规格 | 结果 | 判定 |
|---|---|---|
| FR-08/09 无限多轮与打断 | 总门要求现场三轮完整事件链、一次真实打断及取消后接续 | ALIGNED，不替代历史长稳态 |

| FR-17 本地部署 | 干净机报告必须同revision、身份隔离、五项clean、离线及完整生命周期 | ALIGNED |
| NFR-04 隐私 | 聚合器不复制声音、正文、操作者、身份哈希或绝对路径 | ALIGNED |
| NFR-06 可审计 | 发布文件逐项SHA，不接受顶层自报或跨版本拼接 | ALIGNED |
| NFR-10 许可证 | 个人/研究V1可出门；Wav2Lip商业NO-GO在总报告中继续保留 | ALIGNED |

结论：AC09不扩大功能承诺，只让既定最终验收具备同提交、可重复、失败关闭的出门判定。
