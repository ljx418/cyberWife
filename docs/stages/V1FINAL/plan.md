# V1FINAL 开发计划：外部门机器取证与发布收口

**日期**：2026-10-06
**状态**：工具开发与自动回归完成；现场执行待用户准备

## 目标

V1RC1 已通过所有可无人值守执行的功能、性能、资源、隐私和生命周期门。本阶段不新增产品功能，而是把 ACC1 的人工现场步骤升级为“人只负责说话和判断听感，机器自动验证真实链路”，同时消除总文档中的历史状态漂移。干净 Windows 用户与干净 WSL 的独立复现仍必须在真实新环境执行，不允许用当前发行版的克隆冒充。

## 实施顺序

1. 固定 V1FINAL 验收标准与开发前风险审计。
2. 重构 `Invoke-ACC1HumanGate.ps1`，保留显式焦点授权、Narrator 生命周期和受管 Chrome 清理，但不再让操作者自行判断 ASR/TTS/Avatar 技术事件。
3. 新增 headed Chrome 机器取证器：只记录事件类型、轮次、序号、数量、时间和运行快照，不保存音频、字幕或回答正文。
4. 自动证明默认物理输入产生 PCM、至少三轮均有 ASR final/文本 final/音频/播放完成、至少一次打断、旧轮取消及打断后继续完成新轮；绑定当前 active avatar 和协议连接。
5. 人工输入只保留 Narrator 可理解性及口型/Idle 主观评分；任一评分或机器门失败均输出 FAIL。
6. 增加静态合同测试、Node 语法检查、PowerShell AST 检查；不得在无人值守测试中打开窗口或采集麦克风。
7. 同步 PRD、验收计划、里程碑、追踪矩阵和发布冻结的当前事实。

## 不变边界

- 不使用 fake media、授权 WAV、虚拟麦克风或预先录制事件冒充物理输入。
- 不保存原始音频、完整字幕、完整回答、人物照片或绝对私有路径。
- 不自动授予浏览器麦克风权限；必须由操作者在 loopback 页面确认。
- 不修改模型、延迟、资源或许可证门槛。项目所有者于2026-10-07明确把说话态高清化和嘴部自然度提升延期到V2-X；V1仍保留真实嘴部响应、单人物、无黑帧/冻结/遮罩/切换闪动硬门。
- 不自动创建 Windows 用户、注册/注销 WSL 发行版或安装驱动。

## 出门条件

- 取证器的测试、语法与隐私扫描全部通过。
- 有人现场执行时，机器门和人工门分别可归因、可复核且不可互相冒充。
- 总文档不再同时出现“B3～B5未执行”和“B3～B5已通过”等冲突状态。
- 没有真实现场报告前，ACC1 与 INST1-AC06 仍明确保持开放。
