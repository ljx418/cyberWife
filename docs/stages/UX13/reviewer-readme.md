# UX13 人工审查顺序

1. 先播放 `review-intro-idle-outro.mp4`，判断完整体验。
2. 分别播放 `intro-walk-to-camera.mp4` 与 `outro-walk-back-and-sit.mp4`，检查步态、脚底、手部、脸和沙发。
3. 循环播放 `idle-halfbody-10s.mp4` 至少三次，检查全过程是否正脸直视、双眼水平、肩线稳定，以及表情、眨眼、头肩幅度和循环缝。
4. 对照 `idle-contact-sheet.jpg` 与 `intro-contact-sheet.jpg` 快速定位异常时段。

源肖像没有提供下半身；长裙、鞋履、腿部比例和步态均为模型生成，不代表用户真实身体事实。素材尚未激活到当前线上人物。
