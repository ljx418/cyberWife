# UX13 场景开场、半身 Idle 与结束序列

## 用户体验

项目进入时，人物从客厅沙发自然起身并走近固定镜头；到达腰部以上近景后进入低幅 Idle。结束时按同一运动轨迹走回沙发并坐下。三态保持同一人物、服装、客厅、机位和冷暖光关系。

## 实现边界

- 开场：沙发端坐关键帧 → 半身近景关键帧，Wan 首尾帧条件，约5秒。
- Idle：半身近景同图首尾条件，10秒，仅一次轻柔眨眼和浅呼吸。
- 结束：开场视频精确时间反向，保证路径、人物与沙发终点确定一致。
- 审查合成：开场、Idle、结束之间用12帧完整画面交叉过渡；不做人物抠图或局部边缘处理。
- 当前只生成候选，不自动替换线上 Avatar。

## 出门门槛

- 所有视频 768×432、16fps、无黑帧。
- Idle 160帧且首尾 MAE≤3；脸部保持清晰，嘴唇闭合，不出现大幅转头或手势。
- Idle关键帧与视频全过程必须严格正面：鼻梁/下巴居中、双眼水平且等量可见、视线直视镜头、头部无明显yaw/pitch/roll、双肩水平；三分之二侧脸不出门。
- 开场不得出现瞬移、溶解换人、明显滑步、肢体重复或家具形变。
- 结束必须回到沙发坐姿；组合视频切换不得出现黑场或硬切。
- 自动指标通过后仍须人工连续播放签署步态、身份与表情自然度。
