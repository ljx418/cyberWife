# UX13 半身关键帧提示词

**模式**：内置 ImageGen，`identity-preserve`。

## 输入角色

- 身份参考：控制脸、肤色、发型、耳饰与红色V领毛衣。
- 沙发端坐完整场景：控制服装连续性、照明和叙事起点。
- 无人物客厅底图：控制房间几何与蓝调时刻场景。

## 最终提示词规格

在完全相同的客厅中生成同一成年女性走近固定镜头后的写实中近景。人物自然站立，腰部以上构图，位于画面中央略偏右，平静温暖地直视观众，嘴唇轻闭；保留原人物身份、肤色、发型、耳饰、红色V领毛衣以及深色长裙的连续性。沙发在人物身后保持合理距离，落地窗、城市夜景与暖色落地灯保持原位置；人物面部同时接受冷色窗光和暖色轮廓光。面部细节清晰、自然皮肤纹理、双肩可见、头顶留有安全空间，手部自然下垂并基本位于画外。该图同时作为走近镜头过渡的终点和低幅 Idle 的首帧。

限制：不得改变人物、发型、耳饰、服装、房间布局、家具、机位和时间；不得张嘴、露齿、说话、手靠近脸、抱臂、增加肢体、使用全身远景或极端特写；不得出现文字、水印和模糊。

## V2 正脸修订（当前有效）

把半身关键帧修订为严格正面：脸、鼻梁、下巴、颈部与躯干正对镜头；双眼水平、等量可见并直视镜头；头部 yaw/pitch/roll 均为零；双肩水平且对称；嘴唇轻闭，表情平静温暖。只允许修改朝向，必须保持人物身份、脸部比例、肤色、发型、耳饰、项链、红色V领毛衣、深色裙边、人物尺度、客厅、机位、家具与冷暖光不变。

新增负向限制：三分之二侧脸、侧脸、歪头、转头、低头、仰头、视线偏移、双眼不对称、肩膀倾斜、躯干扭转。
