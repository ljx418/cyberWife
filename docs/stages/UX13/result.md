## 视觉检视

抽帧确认人物完成起身、前行、半身近景和反向返回；客厅机位、沙发与灯光保持一致，未使用抠图。半身 Idle 面部清晰、嘴唇闭合，头肩运动明显小于上一版全身候选。

自动检视不能替代连续播放中的步态、脚底接触、换脸感和转场观感。项目所有者已于 2026-10-06 完成人工连续观感批准；素材随后按版本化清单接入运行态。实时说话 Avatar 工件保持不变，不能把本序列误报成口型模型替换。

## 接入设计

人工批准后按以下状态机接入，而不是把组合片永久循环：

```text
页面准备完成 → intro（播放一次） → idle（循环）
开始说话 → 实时Avatar
停止/退出 → idle当前周期收束 → outro（播放一次） → 坐姿封面
```

开场/结束播放期间不开放麦克风，避免播放状态与实时会话竞争；所有视频加载失败时直接回退当前已批准 Idle/静态人物。

## 运行态实施结果

- 页面载入：`intro` 单次播放，结束事件切换到 `idle` 循环。
- 开始对话：实时 H.264 Avatar canvas 覆盖场景序列，不修改既有口型主链。
- 正常停止：停止媒体会话后播放一次 `outro`，并保留坐姿末帧。
- 异常/媒体错误：回退旧 Idle 或静态人物，语音错误处理保持原合同。
- 安装版本：`ux13-frontal-5f7f0586b108`；详细证据见 [`implementation-audit.md`](implementation-audit.md)。
