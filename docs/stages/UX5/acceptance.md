# UX5 验收标准：真实口型同步

**证据目录**：`audit/v1/UX5/`（不入 Git）

| ID | 用户场景与操作 | 真实证据 | 出门门槛 |
|---|---|---|---|
| UX5-AC01 | 向真实 Avatar 会话发送一段授权 TTS | WAV 元数据、PCM POST 时间线、H.264 帧 CSV | WAV 为 16kHz/mono/s16；每包 640 bytes；丢包 0；仅 loopback |
| UX5-AC02 | 听到声音同时观看人物说话 | 封装 MP4、首个音频时钟与首个同 generation 视频帧 | generation 无串线；视频帧时间戳单调；时钟偏差中位数≤40ms、P95≤80ms |
| UX5-AC03 | 对比正确音画与人为错位音画 | `0/±200/±400ms` 分析 JSON | 分析器在控制组中把 0ms 判为最佳或估计最佳偏移绝对值≤80ms；±200/±400ms 不得优于 0ms |
| UX5-AC04 | 角色说话后停止 | 视频、音频能量/嘴部运动时间线 | 有声段嘴部不是冻结帧；停声排空后回到动态待机；无纯黑帧；无持续说话嘴型 |
| UX5-AC05 | 连续采集完整短句 | Avatar `/metrics`、采集器统计 | `inferfps≥25`、`finalfps≥25`、帧序号无倒退、采集进程退出后 session 被释放 |
| UX5-AC06 | 人工审看同一真实输出 | 1–5 分审看表 | 同步准确度、视觉自然度、总体体验各≥4/5；未完成时结论只能为“自动门通过、人工待验”，不得签 UX5 PASS |
| UX5-AC07 | 审查隐私与许可证 | 白盒扫描、连接采样、模型清单 | 无联网上传动作；真人媒体不入 Git；Wav2Lip 继续标注私人非商业限制 |

## 指标口径

- `时钟偏差`是视频帧头时间与发送给 Avatar 的 PCM `clock_ms` 在同一 generation 内的对应误差；它证明调度与传输，不单独证明音素形状正确。
- `嘴部运动响应`使用已生成 avatar 的人脸坐标下半区，不采集新生物特征，不作为身份识别。
- 相对错位校准优先于公共 SyncNet 绝对 LSE。公共 SyncNet 版本与论文评估权重不一致时，绝对值只允许标为诊断数据。
- AC06 是唯一不可由白盒或能量相关性完全替代的感知门；必须保留真实视频供人审查。

## 失败回退

- AC01/02 失败：先修时间基准、PCM 节奏或 generation 栅栏。
- AC03/04 失败：检查 Mel 窗口、脸部 ROI、Wav2Lip 权重与融合；不得只提高 FPS。
- AC05 失败：检查编码背压与 GPU 资源，不降低 25FPS 硬门。
- AC06 失败：保持静态语音降级可用，并重新进入模型/素材优化计划；不得签 V1 全绿。
