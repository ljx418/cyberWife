# UX5 PRD 规格检视

**检视日期**：2026-10-05  
**结论**：范围与 PRD 一致；本阶段补证不新增产品承诺。

| PRD 条目 | UX5 覆盖 | 偏移检查 |
|---|---|---|
| FR-08 端到端 TTS→Avatar | 同一真实 PCM 驱动采集与视频 | 不引入旁路音频 |
| FR-09 旧 turn 不串入新 turn | 按 generation 过滤并检查单调性 | 保留 B3 栅栏语义 |
| FR-10 人物画面与音频同步 | 时间线、错位对照、动态响应、人工审看 | 修复原先只验 FPS 的证据缺口 |
| NFR-02 Avatar ≥25FPS、资源门 | 复用 `/metrics` 并记录 GPU/内存 | 不放宽硬门 |
| NFR-04 本地隐私 | loopback、私有证据目录、无上传 | 不新增公网依赖 |
| NFR-06 可观测性 | session/generation 可追踪，正文不落报告 | 与脱敏合同一致 |
| NFR-10 许可证 | 继续 ResearchOnly 标记 | 不承诺商业发布 |

## 明确不作出的结论

1. 通过传输时钟门不等于嘴型自然度自动通过。
2. Idle 视频首尾相似不等于说话时音画同步。
3. 公共 SyncNet 的绝对 LSE 不等于论文榜单同版本结果。
4. 自动化通过但 AC06 未完成人审时，UX5 和 V1 均不能标记全绿。
