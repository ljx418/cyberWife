# UX11 自然 Idle 与场景融合计划

**状态**：项目所有者已批准执行
**范围**：只改善 Idle 生成与场景融合；不自动替换当前活动人物，不以机器指标代签自然度。

## 开发顺序

1. 删除产品流水线中的眼部局部移植，改由 Wan 正/负向提示词生成完整画面运动。
2. 生成 5 秒完整帧候选，再以完整帧正放/反放构造 10 秒闭环；禁止局部面部抠像。
3. 对批准前候选执行整个人物离线抠像、时序平滑和边缘羽化，保存 Alpha 母版。
4. 用同一母版和四个本地背景确定性预合成场景视频；原始候选、Mask、派生视频均保留哈希和血缘。
5. 执行黑帧、接缝、身份单脸、运动、Mask 闪烁、场景输出和资源门；生成人工审查接触表。
6. 仅在人工确认后才允许激活。自动化成功不等于视觉自然度通过。

## 架构边界

```text
用户原图 → Qwen正面化 → Wan完整帧低幅Idle → 10秒完整帧闭环
                                         ↓
                                  整个人物离线抠像
                                         ↓
                       Alpha母版 → 四个本地背景预合成视频
```

抠像阶段不得编辑眼睛、嘴或任何局部五官。实时对话模型与重型生成模型继续串行运行。
