# UX11 验收标准

| ID | 场景 | 硬门 |
|---|---|---|
| UX11-AC01 | 检查生成实现与结果清单 | `localized_facial_compositing=false`；完整帧全部来自同一 Wan 输出；不存在眼部贴片路径 |
| UX11-AC02 | 播放候选 5 次循环 | 10 秒、160 帧、黑帧 0、首尾 MAE≤3、转折 MAE≤3、恰好一张可检测人脸 |
| UX11-AC03 | 检查动作 | 脸中心 P95≤画面对角线2.5%，脸框面积CV≤3%；机器门不声称能判定自然度 |
| UX11-AC04 | 离线抠像 | 160/160 帧有 Mask；前景不触及上/左右边界；Mask面积无异常跳变；输出不改变源视频 |
| UX11-AC05 | 四场景预合成 | 四个本地背景各有10秒H.264视频，分辨率/帧率/帧数一致，黑帧0，背景哈希与清单一致 |
| UX11-AC06 | 隐私与资源 | 无公网请求；私有人像/视频不进入Git；生成与实时模型不双常驻；结束后服务恢复 |
| UX11-AC07 | 人工视觉门 | 用户检查身份、眨眼、呼吸、边缘、背景融合和循环自然度；未批准不得激活 |
