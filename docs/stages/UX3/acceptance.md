# UX3 验收门

| 用例 | 操作 | 出门门槛 |
|---|---|---|
| UX3-AC01 无标点流式文本 | 逐 token 输入长句 | 18 字前不从词中硬切；文本无丢失、无重复 |
| UX3-AC02 自然分句 | 合成含逗号、句号、问号的真实回复 | 标点保留；短语不被 8～10 字碎切 |
| UX3-AC03 音色缓存 | 同一声音连续合成两句 | 第二句复用同一 speaker key；换声音后 key 改变 |
| UX3-AC04 首响 | Chrome 完整真实链路至少 10 轮 | P95≤7 秒，样本与原始记录可追溯 |
| UX3-AC05 盲听 | CosyVoice 优化前后同文本同音色 | 人工选择优化版比例≥70%，否则回退调度参数 |
