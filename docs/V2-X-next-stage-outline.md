## 1. 阶段目标

在V1人工总验收通过的单人物实时对话基线上，先提高输入鲁棒性、生命周期恢复、动态表现、音画质量、语音表达和桌面沉浸感，再完成多素材、场景、图像理解与记忆工作台。全过程保持约16GB空闲内存、24GB显存、离线优先、单人物和P95首响不高于7秒。

本阶段不提前实施V2-A的多角色、多空间领域迁移、导入导出和外部记忆插件宿主。

## 3. 已完成：V2-X-D0；当前执行：V2-X-D1

D0已通过自动化与人类审查，交付内容如下：

1. 从V1真实运行态采集主屏、设置、极端视口、Idle/说话/打断/恢复和记忆页面基线截图。
2. 把R01～R14逐项映射到页面、状态、后端能力、降级行为和验收证据，拒绝无法验证的形容词。
3. 形成一个可本地打开的中文HTML审查页，包含目标概念图、当前架构/目标架构、总体页面图、逐组件交互、路由关系和逐步用户旅程。
4. 原型必须可操作：输入设备与校准、按键说话、音量/重播、状态微动作、场景/素材、记忆工作台、质量降级提示和桌面安装入口都需展示真实样式与状态反馈。
5. 技术架构图使用HTML/SVG/drawio表达事实；生成式概念图只表达氛围，不作为接口、性能或验收事实证据。
6. 完成概念一致性、PRD越界、实现可行性、硬件预算、隐私和V1回退六类审查后，打开HTML供人类批准。

6. `docs/architecture/v2-x-gap.drawio`：当前/目标差异、里程碑、门槛和退出条件，中文且不超过8页。

## 5. 实施纪律

- 每个子阶段先定验收、再审计、后编码；新增致命或重大风险未闭环时停在文档门。
- 自动化验收必须使用真实模型、真实素材或明确标记的故障注入；mock只验证合同，不能签用户体验门。
- 所有增强均由feature flag和V1回退路径保护；单项失败不得迫使整条对话链迁移。
- 重型生成和实时对话模型不双常驻；峰值RAM/VRAM、首响、打断和一小时稳态逐阶段复测。
- 人工门集中在素材授权、身份保持、Idle/微动作自然度、声音自然度和口型自然度；机器指标不得代签。

## 6. 进入实际开发前必须锁定

1. 三种麦克风模式的默认策略：自动校准、手工灵敏度、按键说话。
2. 状态微动作的幅度、持续时间、缺失素材回退和减少动效行为。
3. CosyVoice首批预设名称、提示语义和禁止改变的音色特征。
4. 音画质量分级阈值、用户可见提示和何时恢复高质量。
5. PWA安装、全屏、自动启动的范围及Service Worker白名单。
6. 多源素材、场景与记忆工作台的V2-X边界，确保不偷跑V2-A实体管理。

上述内容已在D0原型中由项目所有者确认。D1必须把它们固化为具体代码实体、协议、状态机、迁移/回滚和验收合同；D1内部与外部审计P0/P1为0后，无需重复申请普通自动化开发授权，直接按X0→X7顺序执行。高风险、不可逆操作及出现重大规格偏差时仍停线请求人类处理。
