# ADR-009：B2.5、B2、B3 与 B5 的验收证据归属

- **状态**：Accepted
- **日期**：2026-09-25
- **决策人**：项目用户

## 背景

原 B2.5 出门条件同时要求 OX-06 打断与 OX-09 Avatar 故障恢复，但打断能力由 B3 开发，而 B3 又要求 B2/B2.5 先通过，形成阶段门循环。继续沿用旧归属会迫使项目提前开发 B3 或虚假签署 B2.5。

## 决策

在不降低门槛、不减少样本、不改变 V1 规格的前提下，按能力所有者签署证据：

1. **B2.5** 验收首响、音质、安全问候缓存、加速回退、资源、离线和界面回归，即 OX-01～05、07、08、10～12。
2. **B2** 验收 Avatar 正常帧率、故障静态降级、音频不中断和下一轮恢复，即 OX-09。
3. **B3** 验收早/中/晚各 10 次打断、静音 P95≤400ms、旧 generation 零音频/字幕/帧/写入，即 OX-06。
4. **B5** 在发布候选构建上重跑 OX-01～12，并与 AC-01～14、AC-04A 做完整组合回归。

执行顺序固定为：

```text
B2.5 首响/缓存 → B2 Avatar恢复 → B3 打断 → B4 记忆/隐私 → B5 完整组合回归
```

各门槛仍以 PRD 和验收计划为准。前序阶段不得把后序证据标记为 PASS；B5 重跑失败仍阻止 V1 发布。

## 影响

- 消除 `B2.5 PASS → 才能进入 B3 → B3 证据又是 B2.5 PASS 前提` 的循环。
- OX-06、OX-09 没有取消，只改变首次签署阶段并在 B5 再验。
- B2.5 的人类授权声音盲听仍是 OX-02 硬门，不因本 ADR 自动通过。
