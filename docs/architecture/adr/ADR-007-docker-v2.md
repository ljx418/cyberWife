# ADR-007：Docker 容器化作为 V2 目标

## 状态
Accepted — 2026-09-22

## 背景
容器有利于迁移和依赖固化，但 GPU、Docker Desktop/WSL2 网络、卷性能和大模型映射会扩大 V1 风险。当前目标首先是完成本机体验闭环。

## 决策
V1 不创建或依赖 Dockerfile/Compose。V1 通过外置配置、无状态 adapters、明确数据根和健康接口提供容器化接缝。V2 实现镜像、Compose、GPU 配置、卷、迁移、升级和回滚。

## 后果
V1 交付路径更短，但不能宣称“一键迁移”。V2 必须在全新机器复用 V1 全套验收场景，且数据迁移失败可回滚。
