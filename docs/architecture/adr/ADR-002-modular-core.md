# ADR-002：模块化应用核心与外部推理进程

## 状态
Accepted — 2026-09-22

## 背景
产品是单用户本机应用，但多个模型需要不同进程和资源生命周期。全微服务会引入不必要的分布式事务与部署复杂度；把所有推理塞入 Gateway 又会降低故障隔离。

## 决策
业务采用一个模块化 App Gateway；领域与应用逻辑在进程内，LLM、Speech、Avatar 以 ports/adapters 连接外部进程。依赖方向为 API→Application→Domain/Ports，基础设施反向实现 Ports。

## 后果
数据一致性和调试更简单，模型可替换。需维护进程健康、取消与版本契约，但不引入服务发现或消息队列。
