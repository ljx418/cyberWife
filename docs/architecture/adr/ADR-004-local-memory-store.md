# ADR-004：SQLite + FTS5 + sqlite-vec 管理本地记忆

## 状态
Accepted — 2026-09-22

## 背景
V1 是单用户单机，需要事务性删除、文本搜索和语义召回。独立向量数据库会增加进程、备份与删除一致性成本。

## 决策
元数据、会话和记忆使用 SQLite；关键词使用 FTS5；语义向量使用 sqlite-vec。Embedding 采用 CPU 上的 `BAAI/bge-small-zh-v1.5` 适配器。

## 后果
一个事务可保证源记录、FTS 与向量一致删除，备份简单。未来多用户/横向扩展时需重评，但不在 V1/V2 已承诺范围。
