主链路

麦克风帧 → VAD/ASR 增量文本 → TurnCoordinator → LLM token → TTS 音频帧 → 播放时钟 → 口型参数。所有阶段携带同一个 turn_id。

打断链路

检测到用户新语音 → 取消当前 LLM/TTS → 清空播放缓冲 → Avatar 回到 listening → 新 turn 接管。验收必须证明旧回答不再泄漏。

06 · USER JOURNEYS

四条承诺路径，逐步可验

路线严格覆盖 PRD 的首次配置、日常无限多轮、自然打断与故障降级。没有加入云账户、社交分享或主动推送等未承诺范围。

首次见面

03肖像与声音预览、重录、失败可回退
04进入陪伴配置只做一次，随后直达主舞台

01一键启动自动检查并打开 /companion

03流式回应首句尽早播放，字幕同步增量
04持续多轮上下文延续，资源不随轮次泄漏
J-03
打断纠正
01她正在回答界面明确提示“可随时打断”

J-04
故障降级
01发现异常超时/崩溃由健康检查捕获

03解释与选择说人话，可重试、降级或诊断
04恢复原状态恢复不丢轮次，不重复播放
